## 英語圏で人気だが日本語にまだないテーマ

### 1. Base44によるSaaS量産術（Wix買収後の進化）
英語圏ではBase44のチュートリアルが爆発的に増加中。「5つのアプリを30日で作った」「Base44で稼ぐ方法」など実践動画が多数。日本語では基本紹介はあるが「Base44で収益化」「Base44 vs Lovable実践比較」はほぼない。

### 2. Google Antigravity 実践的アプリ開発（エージェントモード活用）
英語圏では「Antigravityだけでコーポレートサイト完成」「AntigravityでAI自動化を構築」など実践動画が大量。日本語では導入・紹介動画はあるが、Agent-firstモードの深掘り実践コンテンツはまだ不足。

### 3. OpenAI Codex デスクトップSuperApp（2026年4月大型アプデ）
ChatGPT + Codex + Atlasブラウザ統合のSuperAppが話題。PCを自律操作する新機能は英語圏で大バズり中。日本語では概要説明はあるがSuperApp統合の実践レビューが不足。

### 4. Kiro IDE のSpec-Driven Development（仕様駆動開発）
AWS発のKiroが「仕様書を先に書いてからコードを生成する」独自アプローチで注目。英語圏ではMasterclassシリーズもある。日本語では勉強会動画が数本あるが体系的チュートリアルがない。

### 5. Trae IDE 2.0 Builder Mode（ByteDance発・完全無料）
英語圏では「Cursorキラー」としてバズ。Builder Modeで自然言語からプロジェクト全体を自動生成。日本語での実践動画がほぼゼロ。

### 6. Devin 2.2 のレガシーコード変換（COBOL→Rust等）
Devinがレガシーコードベース（COBOL, Fortran, Objective-C）をモダン言語に変換する機能で企業導入が加速。$25B評価額で話題。日本語で「Devinでレガシー変換」の実践動画はない。

### 7. AI Coding Challenges（自分のAIコーディングエージェントを作る）
John Crickettの「Build Your Own AI Coding Agent」チャレンジが英語圏で話題。CLI型のAIコーディングエージェントを自作する内容。日本語カバーなし。

### 8. Claude Code vs Cursor「$40/月のメタ」論
英語圏では「Claude Code＋Cursorの併用が2026年の開発者メタ」という論調が主流。トークン効率5.5倍の差など具体的データ付き比較。日本語では「どっちを選ぶべきか」はあるが、併用メタ論は未カバー。

### 9. Micro-SaaS を AI で1週間で作って売る
「5 SaaS Ideas You Can Build And Sell This Week」のような即実践型コンテンツが英語圏で大人気。AIで作ったSaaSをすぐ販売するまでの全プロセスを見せる動画。日本語では概念レベルの紹介のみ。

### 10. YouTube Playables Builder（Gemini 3でゲーム生成）
YouTubeのPlayables Builder Betaで、テキストプロンプトからミニゲームを生成できる機能。英語圏で実験動画が出始めているが日本語カバーはゼロ。

## 日本語で最初にやれば勝てるテーマTOP10

### 1. Trae IDE 2.0 完全攻略（Builder Mode実演）
- 競合度: ほぼゼロ（日本語動画がない）
- 需要: 高い（完全無料でClaude 4/GPT-4oが使える）
- 勝算: ByteDance発で話題性あり、無料なので視聴者が試しやすい

### 2. Google Antigravity エージェントモード深掘り実践
- 競合度: 低い（紹介動画はあるが実践が少ない）
- 需要: 非常に高い（無料・Google製で信頼度高い）
- 勝算: 「Antigravityだけで○○を作る」シリーズ化可能

### 3. Micro-SaaS を AI で7日間で作って実際に売ってみた
- 競合度: ゼロ（日本語でこの形式の動画がない）
- 需要: 高い（副業・個人開発に直結）
- 勝算: 実録形式でエンタメ性も高い

### 4. OpenAI Codex SuperApp 完全ガイド（PC自律操作）
- 競合度: 低い（概要紹介のみ）
- 需要: 高い（ChatGPTユーザーが多い日本市場）
- 勝算: 2026年4月の最新アプデで旬

### 5. Claude Code + Cursor 併用の「開発者メタ」解説
- 競合度: 低い（比較はあるが併用論がない）
- 需要: 高い（両方使っている人が増えている）
- 勝算: データ付き（トークン効率5.5倍差）で説得力あり

### 6. Kiro IDE 仕様駆動開発チュートリアル
- 競合度: ほぼゼロ（体系的な日本語チュートリアルなし）
- 需要: 中～高（AWS系開発者に刺さる）
- 勝算: 「仕様書ファースト」は日本企業文化と相性がいい

### 7. YouTube Playables Builder でAIゲーム作成
- 競合度: ゼロ
- 需要: 高い（YouTube×ゲーム×AIの掛け算）
- 勝算: YouTube公式機能なので長期的に需要増

### 8. AI Coding Agent を自作するチャレンジ
- 競合度: ゼロ
- 需要: 中（エンジニア向け）
- 勝算: 技術系YouTuberとしての権威づけに最適

### 9. Devin 2.2 レガシーコード変換 実演デモ
- 競合度: ゼロ（日本語実践動画なし）
- 需要: 中（エンタープライズ層に刺さる）
- 勝算: 「COBOLをRustに変換」はインパクト大

### 10. Replit Agent 4 でモバイル＋Web＋スライド同時生成
- 競合度: 低い
- 需要: 高い（非エンジニアのアプリ開発需要）
- 勝算: 1つのプロジェクトで複数成果物という新概念

## 補足: 主要統計データ（動画のネタに使える数字）

- バイブコーディング市場規模: $4.7B（2025年）→ $12.3B（2027年予測）
- Fortune 500の87%がバイブコーディングプラットフォームを導入済み
- GitHubコミットの51%がAI生成 or AIアシスト（2026年初頭時点）
- 開発者の85%がAIツールを日常的に使用
- AI生成コードはロジックエラーが75%多く、セキュリティ問題が2倍
- 開発者の96%がAI生成コードを完全には信頼していない
- Claude CodeはCursorの5.5倍トークン効率が良い
- Claude Code: $1あたり精度8.5pt / Cursor: $1あたり精度6.2pt
- Windsurf: 100万+アクティブユーザー、Fortune 500の59%が利用
- Devin（Cognition AI）: $25B評価額で資金調達交渉中
- Replit: $9B評価額、$400M資金調達（2026年3月）
