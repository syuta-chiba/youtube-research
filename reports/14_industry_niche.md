## 「業界特化AI」シリーズ企画案

### シリーズコンセプト
**「○○業界のためのAI入門」シリーズ** - 各業界の現場で働く人が「今日から使える」AI活用法を、業界の言葉で、業界の課題に即して解説する。

### シリーズ構成（全20回想定）

**Phase 1: 人手不足業界編（再生数が取れやすい）**
- 第1回「介護 x AI」- 記録・申し送り・ケアプラン作成
- 第2回「建設 x AI」- 工程表・安全書類・写真整理
- 第3回「物流 x AI」- 配車計画・ルート最適化
- 第4回「農業 x AI」- 病害虫診断・収穫予測

**Phase 2: 士業・専門職編（高単価案件につながる）**
- 第5回「税理士 x AI」- 記帳代行・申告書・顧問レポート
- 第6回「弁護士 x AI」- 契約書レビュー・判例検索
- 第7回「医師 x AI」- カルテ作成・画像診断補助
- 第8回「教師 x AI」- テスト作成・通知表・授業準備

**Phase 3: 店舗ビジネス編（視聴者が幅広い）**
- 第9回「飲食店 x AI」- メニュー開発・仕入れ・口コミ対応
- 第10回「美容室 x AI」- カウンセリング・予約管理・SNS集客
- 第11回「小売店 x AI」- 在庫管理・POP作成・顧客分析
- 第12回「宿泊業 x AI」- 予約対応・多言語対応・レビュー管理

**Phase 4: オフィスワーク編（バズりやすい）**
- 第13回「不動産 x AI」- 物件査定・契約書・営業メール
- 第14回「人事 x AI」- 採用スクリーニング・評価・研修
- 第15回「経理 x AI」- 請求書処理・経費精算・予算管理
- 第16回「広報 x AI」- プレスリリース・SNS運用・メディア対応

**Phase 5: ニッチ産業編（コアファン獲得）**
- 第17回「漁業 x AI」- 漁場予測・鮮度管理
- 第18回「林業 x AI」- 森林調査・伐採計画
- 第19回「葬儀業 x AI」- 手配管理・追悼文作成
- 第20回「寺院 x AI」- 檀家管理・法話準備

### 各回の統一フォーマット
1. その業界の「あるある課題」を3つ提示（共感パート：1分）
2. AIで解決できる業務を具体的にデモ（実演パート：5分）
3. 明日からの導入ステップ3つ（行動促進パート：2分）
4. 業界の先行事例紹介（信頼構築パート：2分）

## 1本の動画で複数業界を狙える企画

### 企画1:「全業界共通！AIで○○する方法」シリーズ

**「AIで見積書を10倍速く作る方法 - 建設・製造・IT・デザイン全部対応」**
- 建設の積算、製造の原価計算、IT案件の工数見積り、デザインの料金表をすべてカバー
- 各業界の見積書テンプレートをAIで生成するデモを実演
- ターゲット: 見積書を作るすべてのビジネスパーソン

**「AIで報告書を自動作成！業界別テンプレート10選」**
- 施工報告書、診療記録、介護日誌、営業日報、研修報告書など横断的にカバー
- 共通のプロンプト構造を教えた上で業界別カスタマイズを紹介
- ターゲット: 報告書作成に時間を取られている全業種の現場担当者

### 企画2:「業界対決！AIで一番変わる業界はどこだ？」

**「【ガチ検証】5業界のプロにAIを渡して1週間！最も効率化できた業界は？」**
- 介護士、建設現場監督、税理士、農家、美容師の5人が参加
- 各自がChatGPT/Claudeを1週間業務で使い、時間削減効果を比較
- 視聴者投票で「最もAIが必要な業界」を決定
- ターゲット: AI興味層 + 各業界の従事者（複数業界を一気に取り込む）

**「あなたの業界、AIに奪われる？奪われない？10業界ランキング」**
- 各業界のAI代替リスクを具体的に解説
- 「奪われる仕事」ではなく「AIと共存して価値が上がる仕事」にフォーカス
- コメント欄で「自分の業界はどうなる？」の議論を促進（エンゲージメント向上）
- ターゲット: 将来不安を持つ全業種の社会人

### 企画3:「AIが使えない業界の人こそ見てほしい」

**「アナログ業界ほどAIで差がつく！建設・農業・介護のAI革命最前線」**
- 「デジタルに疎い業界」という固定観念を覆す内容
- 各業界で実際にAIを導入して成果を出した人のインタビュー
- スマホだけで始められるAI活用法を紹介
- ターゲット: IT苦手意識のある現場労働者

**「ChatGPTを知らない上司に見せる動画 - 全業界対応AI導入プレゼン資料付き」**
- 上司・経営層を説得するためのデータとロジックを提供
- 業界別のROI試算（○○業界なら月○時間削減 = 年間○万円の効果）

## 総括: 最優先で攻めるべき3領域

### 1. 介護 x AI
- 理由: 最大の人手不足業界 x YouTube動画ほぼゼロ = 最大の穴場
- 215万人の介護職員という巨大ターゲット
- 社会的意義が高く、メディア露出のチャンスも大きい

### 2. 建設 x AI
- 理由: 2024年問題で切実なニーズ x 動画供給が極少
- 現場監督は移動時間が長くYouTube視聴習慣がある
- 実演デモが映えるコンテンツを作りやすい

### 3. 税理士・会計 x AI
- 理由: 専門性が高く参入障壁がある x 完全な空白地帯
- 高所得層へのリーチ = 高CPMが期待できる
- 繁忙期（確定申告シーズン）に検索が集中するため季節戦略が立てやすい
