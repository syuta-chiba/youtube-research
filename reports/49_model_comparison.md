## 英語圏の比較動画フォーマット分析

### 1. 主要な動画フォーマット（6タイプ）

**A. "Which Is Worth $20/Month?" 価格対決型**
- 例: "ChatGPT vs Claude vs Gemini: Which AI Is Worth $20/Month in 2026?"
- 特徴: 月額課金を切り口に、3社のPro/Plusプランを同一タスクで比較
- 再生数: 高い（消費者の購買決定に直結するため）
- 構成: 料金表 → 5-7テスト → 総合スコア → おすすめ判定

**B. "I Tested So You Don't Have To" 代行テスト型**
- 例: "I Tested Gemini vs Claude vs ChatGPT So You Don't Have To"
- 特徴: 長時間テストの結果をダイジェストで見せる
- フック: 「あなたの代わりにやりました」という時間節約訴求
- 構成: テスト設計説明 → 各モデルの回答映像 → 採点 → 結論

**C. "5 Tests / 7 Impossible Tests" テスト回数明示型**
- 例: "Claude vs ChatGPT vs Gemini: 5 Tests"、Tom's Guide "7-0 wipeout: 7 impossible tests"
- 特徴: テスト数をタイトルに明示し、視聴者に体系的な比較を期待させる
- 構成: テスト1（コーディング）→ テスト2（ライティング）→ ... → 最終スコア

**D. "Tier List" ランク付け型**
- 例: "The Definitive AI Tier List for March 2026"、"AI Model Tier List for Agentic Workflows"
- 特徴: S/A/B/C/Dランクで視覚的にランキング。Shorts向きでもある
- 構成: カテゴリ説明 → 各モデルのランク発表 → 議論 → 最終ティアリスト画像

**E. "GPT-5.5 vs Claude Opus 4.7" 最新モデル直接対決型**
- 例: "I Didn't Expect This: Opus 4.7 vs GPT 5.5"
- 特徴: 新モデルリリース直後に速報的に出す。鮮度が命
- 構成: モデル概要 → ベンチマーク比較 → 実タスクテスト → 意外な結果の強調

**F. "Honest Review" 正直レビュー型**
- 例: "Ranking Every AI Tool I Used in 2026 (What's ACTUALLY Good)"
- 特徴: スポンサーなしを強調し、個人の体験ベースで語る
- 構成: 使用履歴開示 → 良い点/悪い点 → 本音のおすすめ

### 2. 英語圏の共通パターン

| 要素 | 詳細 |
|------|------|
| サムネイル | 3社ロゴ並列 + "WINNER?" or "BEST?" テキスト |
| タイトル構造 | "A vs B vs C: [疑問文] in 2026" |
| 動画の長さ | 15-25分（ロング）/ 60秒（Shorts） |
| テスト項目 | コーディング、ライティング、推論、画像理解、価格 |
| 結論パターン | 「万能の勝者はいない。用途で使い分けろ」が90%以上 |
| ベンチマーク引用 | SWE-bench Verified、GPQA Diamond、ARC-AGI-2、LM Arena Elo |
| 再生数の傾向 | 新モデルリリース48時間以内が最大トラフィック |

### 3. 人気クリエイターの特徴的アプローチ

- **テック系**: ベンチマークスコアを画面共有しながら解説。データ重視
- **ビジネス系**: 「ビジネスで使うならどれ？」のフレーム。ROI議論
- **開発者系**: Claude Code vs Codex の実演コーディング比較。ターミナル画面録画
- **カジュアル系**: 「友達にどれをすすめるか」の日常視点

## 日本語でまだない比較の切り口

### 英語圏にあって日本語圏にない/少ないコンテンツ

1. **Codex vs Claude Code のガチ開発比較**
   - 英語圏ではCodex vs Claude Codeの実演比較が大量にある
   - 日本語では「Claude Codeとは？」レベルの紹介動画が主で、実践比較がほぼない

2. **DeepSeek V4 を含む4社比較**
   - 英語圏ではDeepSeek V4（$1.74/M tokens）のコスパ破壊力が大きな話題
   - 日本語圏ではDeepSeekの深掘りが少なく、3社比較で止まっている

3. **APIコスト計算の実務比較**
   - 英語圏: 「同じタスクでGPT-5.5は$35、DeepSeekは$5.22」のような具体計算
   - 日本語圏: 月額プランの比較はあるが、API課金の実務計算動画がない

4. **エンタープライズ市場シェア分析**
   - Anthropicがエンタープライズコーディング市場の54%を占有
   - Anthropic年間売上$30B（2026年）vs OpenAIの規模比較
   - 日本語圏ではビジネスインパクトの分析動画がほぼない

5. **Agentic Workflow（エージェント型ワークフロー）の比較**
   - 英語圏: "AI Model Tier List for Agentic Workflows" のような専門比較
   - 日本語圏: エージェント機能の比較がほぼ未開拓

6. **日本語特有の性能テスト**
   - 敬語の使い分け精度、ビジネスメール品質、日本の法律文書理解
   - 英語圏の比較フォーマットを日本語タスクに翻案する動画が不足

7. **ローカルAIモデル（GLM-5等）との比較**
   - 英語圏: GLM-5（オープンソース、SWE-bench 77.8%）が話題
   - 日本語圏: ローカルAIの実用比較がほぼない

## 差別化できる比較フォーマット提案

### フォーマット1: 「日本語ガチテスト」シリーズ
- 英語圏の比較は全て英語タスク。日本語での実力差は未検証領域
- 敬語メール、議事録要約、契約書チェック、技術文書翻訳を比較
- 差別化ポイント: 日本語ネイティブにしか判定できない品質差を可視化

### フォーマット2: 「月額○万円分のAI、どう使い分ける？」
- 複数AI課金の最適ポートフォリオを提案
- Claude Pro + Gemini無料 + DeepSeek APIという組み合わせ提案
- 差別化ポイント: 「1つ選ぶ」ではなく「組み合わせ最適化」という新視点

### フォーマット3: 「開発者の1日密着 × AI比較」
- 実際の開発タスク（バグ修正、新機能実装、コードレビュー）でClaude Code vs Codexを実演
- ターミナル画面を見せながらリアルタイム比較
- 差別化ポイント: ベンチマークではなく実務での体感差を見せる

### フォーマット4: 「企業の中の人が本音で語る」インタビュー型
- 実際にAIを業務導入した企業担当者にインタビュー
- 差別化ポイント: 個人レビューではなく組織レベルの知見

### フォーマット5: 「AIコスト計算機」実務型
- API利用量ごとの月額コストを具体計算
- DeepSeek V4 ($1.74/M) vs Claude Opus 4.7 ($5/M入力, $25/M出力) vs GPT-5.5 ($5/M入力, $30/M出力)
- 差別化ポイント: 日本語圏で最も不足しているAPI経済性の分析

## emperor_ch用の比較動画企画10本

### 企画1: 「【2026年決定版】ChatGPT vs Claude vs Gemini、日本語で本気テストしたら意外な結果に」
- 内容: 日本語タスク7つ（敬語メール、議事録要約、プレゼン資料作成、技術文書翻訳、創作小説、法律相談、コーディング）で3社を比較
- 想定尺: 20分
- フック: 「英語では○○が最強だけど、日本語では結果が全く違った」
- ターゲット: AI初心者〜中級者、ビジネスパーソン

### 企画2: 「Claude Code vs Codex ガチ対決！現役エンジニアが本気でアプリを作ってみた」
- 内容: 同じアプリ（ToDoアプリ or チャットボット）をClaude CodeとCodexそれぞれで制作し、所要時間・コード品質・バグ数を比較
- 想定尺: 25分
- フック: 「エンジニアの70%がClaudeを選ぶ理由がわかった」
- ターゲット: 開発者、プログラミング学習者

### 企画3: 「【衝撃】DeepSeek V4が安すぎる。GPTとClaudeの1/7の価格で同等性能？」
- 内容: DeepSeek V4のAPIコストとパフォーマンスを検証。同一タスクでのコスト比較表を作成
- 想定尺: 15分
- フック: 中国発AIが価格破壊を起こしている事実
- ターゲット: 開発者、スタートアップ経営者

### 企画4: 「AI課金ガイド2026年版｜月3,000円で最強の組み合わせを見つけた」

- 想定尺: 18分
- フック: 全部に課金する必要はない
- ターゲット: コスパ重視の一般ユーザー

### 企画5: 「GPT-5.5 vs Claude Opus 4.7 ガチ対決｜7つのテストで完全決着」
- 内容: 英語圏のTom's Guideフォーマットを日本語に翻案。7つの「不可能なテスト」で対決
- 想定尺: 22分
- フック: 「7-0で完封」のような劇的な結果を期待させる
- ターゲット: 最新モデルに興味がある技術層

### 企画6: 「【AIティアリスト2026】全モデルをS〜Dランクに格付けしてみた」
- 内容: GPT-5.5、Claude Opus 4.7、Gemini 3.1 Pro、DeepSeek V4、Grok 4、GLM-5をカテゴリ別にティアリスト化
- 想定尺: 15分（Shorts版も制作可能）
- フック: 視覚的なティアリスト画像のサムネイル
- ターゲット: 幅広いAI関心層

### 企画7: 「AIに敬語メールを書かせたら、どれが一番"日本人っぽい"？」
- 内容: ビジネスメール（お断り、催促、お詫び、依頼）を各AIに書かせ、日本人ネイティブ複数名が評価
- 想定尺: 12分
- フック: 日本語でしかできない比較テスト
- ターゲット: ビジネスパーソン、事務職

### 企画8: 「エージェント型AIの未来｜Claude Code・Codex・Geminiが自律的に仕事をする時代」
- 内容: エージェント型ワークフロー（自律的にファイル操作、テスト実行、Git管理）の比較と解説

- フック: 「AIが勝手にコードを書いてプルリクまで出す」
- ターゲット: 開発者、テックリーダー

### 企画9: 「OpenAI vs Anthropic vs Google｜3社の戦略を徹底分析【2026年最新】」
- 内容: 企業戦略・売上・IPO動向・安全性アプローチの比較。Anthropic $30B売上、OpenAI $852B評価額などのデータを解説
- 想定尺: 18分
- フック: 技術ではなくビジネスの視点でAI業界を読み解く
- ターゲット: ビジネス・投資に関心がある層

### 企画10: 「AIを乗り換えるべき？ChatGPT→Claude移行ガイド【実体験】」

## 調査から得られた重要インサイト

### 英語圏の市場動向（2026年4月時点）

1. **モデル収束**: GPT-5.4、Claude Opus 4.6、Gemini 3.1 Proの性能差はベンチマーク上では僅差。差別化は「得意分野」に移行
2. **コスト崩壊**: DeepSeek V4がフロンティアモデルの1/7〜1/50の価格で90%の性能を実現
3. **エージェント時代**: Claude Code vs Codex の対決が開発者コミュニティの最大関心事
4. **企業競争激化**: Anthropic年間売上$30B、OpenAI評価額$852B。両社2026年後半にIPO予定
5. **「1つ選ぶ」から「使い分ける」へ**: 英語圏の結論はほぼ100%「用途別に使い分けろ」

### 日本語圏の機会

1. **日本語品質テスト**: 英語圏には絶対にできない領域。参入障壁が高い
2. **API経済性の解説**: 日本語での詳細なAPI課金分析がほぼゼロ
3. **エージェント型AI**: Claude Code/Codexの日本語実践動画が皆無に近い
4. **DeepSeek/GLM-5の紹介**: 中国発モデルの日本語での詳細レビューが不足
5. **企業導入事例**: 日本企業のAI活用事例を交えた比較が差別化要素になる
