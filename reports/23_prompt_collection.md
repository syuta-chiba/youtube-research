## 1. 企画立案

### 1-1. 動画アイデア量産プロンプト

```
あなたはYouTubeコンテンツ戦略のプロフェッショナルです。

以下の条件でYouTube動画の企画アイデアを20個提案してください。

# チャンネル情報
- チャンネルジャンル: [AI・テクノロジー]
- チャンネル登録者数: [約○万人]
- ターゲット視聴者: [30〜40代のビジネスパーソン、AIに興味があるが専門知識は少ない]
- 過去に伸びた動画テーマ: [ChatGPTの使い方、AI副業、画像生成AI]
- 最近避けたいテーマ: [すでに飽和しているネタなど]

# 条件
- 2026年4月時点のトレンドを意識
- 初心者でも理解できる内容
- 再生回数が伸びやすい「検索需要」があるテーマを優先
- 各アイデアに「仮タイトル」「想定再生時間」「狙うキーワード」「差別化ポイント」を記載

# 出力フォーマット
| No. | 仮タイトル | 再生時間 | 狙うキーワード | 差別化ポイント | 優先度(A/B/C) |
```

## 2. 台本作成

### 2-1. フル台本作成プロンプト（メイン）

```
あなたはチャンネル登録者100万人のAI系YouTuberの専属ライターです。
以下の条件で、YouTube動画の台本を作成してください。

# 動画情報
- テーマ: [例: ChatGPT o3の衝撃的な新機能5選]
- 想定再生時間: [12分]
- ターゲット: [AIツールを仕事に活用したい30代会社員]
- トーン: [親しみやすく、驚きを演出しつつも正確に]
- 一人称: [僕]
- チャンネル名: [○○チャンネル]

# 台本構成
1. フック（冒頭5秒）: 視聴者の心をつかむ衝撃的な一言
2. オープニング（30秒）: 挨拶 + 今日の動画の概要 + 「最後まで見る理由」
3. 本編（10分）: テーマに沿った解説（画面操作の指示も含む）
4. まとめ（1分）: 要点の振り返り
5. エンディング（30秒）: チャンネル登録・高評価の呼びかけ + 次回予告

# 出力ルール
- 話し言葉で書く（「〜ですね」「〜なんですよ」などの口語体）
- テロップ指示を【テロップ: ○○】で挿入
- 画面切り替え指示を【画面: ○○】で挿入
- BGM変更指示を【BGM: ○○な雰囲気に変更】で挿入
- 各セクションの推定所要時間を記載
- 視聴者維持率を高める「引き」を2〜3分ごとに入れる
```

### 2-2. ショート動画台本プロンプト

```
YouTube Shorts（60秒以内）の台本を作成してください。

# テーマ: [例: AIで1分で名刺をデザインする方法]
# ターゲット: [AI初心者]
# トーン: [テンポよく、驚きを重視]

# 構成ルール
- 冒頭1秒: 衝撃的なフック（「これ知らない人、損してます」系）
- 0:02〜0:10: 問題提起 or 結果を先に見せる
- 0:10〜0:45: 手順を3ステップ以内で簡潔に
- 0:45〜0:55: 結果のビフォーアフター
- 0:55〜0:60: CTA（「フォローして他のAI技も見てね」）

# 注意
- 1文は15文字以内を目安に
- 「え、まじ？」と思わせるギャップを入れる
- テロップ指示も含める
```

## 3. タイトル生成

### 3-1. 高CTRタイトル生成プロンプト

```
以下の動画内容に対して、クリック率（CTR）が高くなるYouTubeタイトルを10個作成してください。

# 動画内容
[例: Claude 4の新しいコード生成機能を使って、プログラミング未経験者がWebアプリを作る過程を紹介]

# タイトル作成ルール
- 28〜45文字以内（YouTube表示で切れない長さ）
- 以下のパターンをそれぞれ2つずつ:
  A) 数字を含むタイトル（例: 「○選」「○つの方法」）
  B) 疑問形タイトル（例: 「○○って実際どうなの？」）
  C) 衝撃・意外性タイトル（例: 「○○が○○だった件」）
  D) ベネフィット訴求タイトル（例: 「○○するだけで○○できる」）
  E) 時事性・速報タイトル（例: 「【速報】○○が発表」）

# 各タイトルに以下を付記
- 想定CTR（高/中/低）
- 狙うSEOキーワード
- どの視聴者層に刺さるか
```

### 3-2. A/Bテスト用タイトル生成プロンプト

```
以下のYouTubeタイトルのA/Bテスト用バリエーションを作成してください。

# 元のタイトル
「[例: 【2026年最新】ChatGPTで副業月10万円稼ぐ完全ロードマップ]」

# 作成するバリエーション
1. 元タイトルのキーワード順序を変えたもの
2. 感情を強調したもの
3. 具体的な数字を変えたもの
4. 疑問形に変換したもの
5. ネガティブ訴求に変えたもの（「○○しないと損」系）

# 各バリエーションに「元タイトルとの違い」と「予想される効果」を記載してください。
```

### 5-1. SEO最適化 説明欄テンプレート生成プロンプト

```
以下の動画のYouTube説明欄（概要欄）を作成してください。

# 動画情報
- タイトル: [動画タイトルを入力]

- 関連リンク: [紹介したツールのURL等]
- SNSリンク: [Twitter: @○○ / Instagram: @○○]

# 説明欄の構成
1. 冒頭3行（折りたたみ前に表示される部分）
   - 動画の要約（検索キーワードを自然に含む）
   - 視聴メリットを一文で
2. タイムスタンプ（チャプター）
   - 00:00 の形式で主要セクションを記載
3. 関連リンク

4. 関連動画

5. SNS・お問い合わせ
6. 検索用キーワード（自然な文章で3行程度）

# SEOルール
- 主要キーワードを冒頭100文字以内に含める
- 関連キーワードを自然な形で5〜8個散りばめる
- ハッシュタグを3〜5個（末尾）
```

## 8. コメント返信

```
"""
```

## 9. 競合分析

```

# 自チャンネル情報
- チャンネル名: [自分のチャンネル名]
- 登録者数: [○万人]
- 主なテーマ: [AI・テクノロジー解説]

# 競合チャンネル情報（わかる範囲で）
- チャンネル名: [競合チャンネル名]

  1. [タイトル1]

  3. [タイトル3]

# 分析項目
1. SWOT分析（自チャンネル vs 競合）
2. コンテンツ戦略の違い（テーマ選定・切り口）
3. サムネイル・タイトルの傾向比較

5. 視聴者層の違い（推定）
```

## 使い方のコツ

1. **段階的に使う**: 企画立案 → 台本作成 → タイトル生成 → 説明欄の順で使うと効率的
2. **前の出力を次の入力に**: 企画プロンプトの出力結果を台本プロンプトの入力に使い回す
3. **フィードバックループ**: AIの出力をそのまま使わず、修正指示を追加で出す（「もっとカジュアルに」「フックを3パターン追加して」等）
4. **データを蓄積**: 実際の動画パフォーマンスをアナリティクス分析プロンプトに入力し、次の企画に活かす
5. **ロール設定を固定**: お気に入りのシステムプロンプトを見つけたら、毎回の会話冒頭で設定する
