# AI系YouTube 動画制作ワークフロー完全ガイド
日付: 2026-04-20

## 制作フロー全体像（企画→投稿）

AI系YouTube動画の制作は、以下の6工程に分かれる。2026年現在、各工程にAIツールを組み込むことで、**制作時間を従来の60〜80%削減**できることが報告されている。

### 全体フロー

```
企画（30分）→ 台本（1時間）→ 素材準備（30分）→ 撮影/録画（30分〜1時間）→ 編集（1〜2時間）→ サムネ・メタデータ（30分）→ 投稿
```

**従来**: 1本あたり6〜10時間（初心者）/ 3〜5時間（中級者）
**AI活用後**: 1本あたり2〜3時間（目標）

### 工程別の詳細

| 工程 | 内容 | 所要時間(AI活用) | 主要AIツール |
|------|------|-----------------|-------------|
| 1. 企画 | テーマ選定・競合調査・構成案 | 30分 | ChatGPT / Claude / NoimosAI |
| 2. 台本 | 台本執筆・推敲 | 30分〜1時間 | ChatGPT / Claude / Gemini |
| 3. 素材準備 | 画像・動画素材の収集・生成 | 30分 | Midjourney / DALL-E 3 / Veo 3.1 |
| 4. 撮影/録画 | 画面録画・デモ撮影 | 30分〜1時間 | OBS Studio |
| 5. 編集 | カット・字幕・BGM・エフェクト | 1〜2時間 | Vrew / CapCut / Premiere Pro |
| 6. 仕上げ | サムネイル・タイトル・説明文・タグ | 30分 | サムネAI / Canva / ChatGPT |
| 7. 投稿 | アップロード・予約投稿 | 10分 | YouTube Studio |

## 顔出しなし動画の制作方法

### 顔出しなし動画の5つのスタイル

1. **画面録画+AI音声型**（AI系チャンネルに最適）
   - OBSでツールのデモを画面録画
   - VOICEVOXまたはElevenLabsでナレーション
   - Vrewで字幕自動挿入
   - 最も手軽で、AI系動画との相性が抜群

2. **スライド解説型**
   - Canva/PowerPointでスライド作成
   - AI音声でナレーション
   - スライドの切り替えで視覚的に解説

3. **AIアバター型**
   - HeyGen / Vidnoz等のAIアバターが解説
   - 230種類以上のアバターから選択可能
   - 140以上の言語に対応

4. **AI動画生成型**（フルAI）
   - InVideo AI / FlowShorts等で台本→動画を全自動生成
   - テキスト入力のみで完成動画を出力
   - ショート動画の量産に最適

5. **アニメーション・モーショングラフィックス型**
   - 図解やアニメーションで説明
   - Canva / CapCutのテンプレートを活用

### 顔出しなしAI系動画の推奨ワークフロー

```
1. Claude/ChatGPTで台本作成
2. OBSで画面録画（AIツールのデモ操作）
3. VOICEVOXでナレーション音声生成
4. Vrewで自動字幕+無音カット
5. CapCut/Premiere Proで最終編集（BGM・テロップ追加）
6. サムネAI/CanvaでサムネイルAI生成
7. YouTube Studioでアップロード・予約投稿
```

### 必要な機材

顔出しなしの場合、カメラ・照明・背景は一切不要。必要なのは:
- PC（スペックはそこそこでOK）
- マイク（自分の声を使う場合のみ）
- 安定したインターネット回線

## AI活用で制作時間を半分にする方法

### 時間削減の具体的ポイント

| 工程 | 従来の方法 | AI活用後 | 削減率 |
|------|-----------|---------|--------|
| 企画・リサーチ | 2時間 | 30分 | 75% |
| 台本作成 | 3時間 | 30分〜1時間 | 70〜83% |
| 字幕作成 | 2時間 | 5分（自動生成） | 96% |
| 無音カット | 1時間 | 1分（自動） | 98% |
| サムネイル | 1時間 | 10分 | 83% |
| SEO・メタデータ | 30分 | 10分 | 67% |
| **合計** | **9.5時間** | **約2.5時間** | **74%** |

### AI活用の5大戦略

1. **台本のAI下書き→人間が編集**
   - ChatGPT/Claudeにテーマとターゲットを指定して構成案+台本を生成
   - 自分の経験や独自の視点を追加して差別化
   - 所要時間: 3時間→30分

2. **Vrewで字幕+無音カットを自動化**
   - 動画をVrewに読み込むだけで字幕自動生成
   - 無音部分を一括カット
   - テンポの良い動画が自動的に完成
   - 所要時間: 3時間→10分

3. **AI音声でナレーション不要化**
   - VOICEVOXやElevenLabsで台本を読み上げ
   - 録り直し・噛み直しがゼロに
   - 所要時間: 1時間→10分

4. **サムネイルのAI自動生成**
   - サムネAIやCanva AIでワンクリック生成
   - A/Bテスト用に複数バリエーションを即座に作成
   - 所要時間: 1時間→10分

5. **ショート動画の自動切り出し**
   - CapCutの「長編→短編」機能で自動的にショート動画を量産
   - 1本の動画から3〜5本のショートを自動生成
   - 追加の制作時間ほぼゼロ

## 1日1本投稿を実現するバッチ制作法

### バッチ制作の基本戦略

**週末2日で平日5本分を一括制作**するのが最も効率的。

#### 土曜日（企画・台本デー）
| 時間 | 作業 | 詳細 |
|------|------|------|
| 10:00-11:00 | テーマ選定 | 5本分のテーマをAIでブレスト |
| 11:00-13:00 | 台本作成 | 5本分の台本をAIで下書き→編集 |
| 14:00-16:00 | 素材準備 | 画像・動画素材の収集・AI生成 |
| 16:00-18:00 | ナレーション | VOICEVOXで5本分の音声を一括生成 |

#### 日曜日（撮影・編集デー）
| 時間 | 作業 | 詳細 |
|------|------|------|
| 10:00-12:00 | 画面録画 | 5本分のデモ操作をOBSで連続録画 |
| 13:00-17:00 | 編集 | Vrewで字幕+カット→最終編集 |
| 17:00-18:00 | サムネ・メタデータ | 5本分のサムネとタイトル・説明文作成 |
| 18:00-18:30 | 予約投稿 | YouTube Studioで月〜金に予約設定 |

### 予約投稿のコツ

- **最適な投稿時間**: 視聴者の活動時間に合わせる（一般的に平日18:00〜21:00）
- **YouTube Studioの予約機能**: 公開設定で「スケジュール設定」を選択し、日時を指定
- **注意点**: 予約投稿でも再生数に影響はないが、初速が重要なため視聴者のアクティブ時間に設定
- **管理ツール**: Hootsuite等のSNS管理ツールで一括管理も可能

### テンプレート化のポイント

- **動画のフォーマットを統一**: OP→フック→本編→まとめ→CTAの構成を固定
- **テロップスタイルの統一**: フォント・色・サイズをプリセット保存
- **BGMリストの固定**: 使い回しOKなBGMを10曲程度ストック
- **サムネテンプレート**: 配色・レイアウトのテンプレートを3パターン用意

## 制作テンプレート（チェックリスト）

### 動画1本の制作チェックリスト

#### Phase 1: 企画（30分）
- [ ] テーマ・タイトル案を決定
- [ ] 競合動画を3本以上リサーチ
- [ ] ターゲット視聴者とゴールを明確化
- [ ] 動画の尺を決定（目安: 8〜15分）
- [ ] キーワードを選定（vidIQ/TubeBuddy活用）

#### Phase 2: 台本（30分〜1時間）
- [ ] AIで構成案を生成（フック→本編→まとめ→CTA）
- [ ] AIで台本の下書きを生成
- [ ] 自分の経験・独自の視点を追加
- [ ] 冒頭15秒のフック（結論の予告）を確認
- [ ] 台本の最終チェック・音読確認

#### Phase 3: 素材準備（30分）
- [ ] 必要な画像をAI生成 or フリー素材サイトから収集
- [ ] BGMを選定
- [ ] SE（効果音）を準備
- [ ] デモ操作の手順を確認

#### Phase 4: 撮影/録画（30分〜1時間）
- [ ] OBSの設定確認（解像度・FPS・音声）
- [ ] 画面録画を実施
- [ ] （AI音声の場合）VOICEVOXでナレーション生成
- [ ] 素材の整理・リネーム

#### Phase 5: 編集（1〜2時間）
- [ ] Vrewで動画読み込み→自動字幕生成
- [ ] 無音部分の自動カット
- [ ] 字幕のスタイル調整
- [ ] BGM・SEの挿入
- [ ] テロップ・エフェクトの追加
- [ ] OP/ED（共通パーツ）の挿入
- [ ] 最終プレビュー確認
- [ ] 書き出し（1080p/60fps）

#### Phase 6: 仕上げ（30分）
- [ ] サムネイル作成（サムネAI / Canva）
- [ ] タイトル最終決定（32文字以内推奨）
- [ ] 説明文作成（AIで下書き→編集）
- [ ] タグ設定
- [ ] カード・終了画面の設定
- [ ] チャプター（タイムスタンプ）の追加

#### Phase 7: 投稿（10分）
- [ ] YouTube Studioにアップロード
- [ ] サムネイル設定
- [ ] 公開設定（即時 or 予約投稿）
- [ ] 再生リストへの追加
- [ ] コミュニティ投稿で告知（任意）
