## 各ジャンル詳細

### 1. AI画像生成（Midjourney, Stable Diffusion, DALL-E, Flux等）

- **盛り上がり: B** -- 2024年のブーム期を過ぎ、成熟フェーズに入っている。GPT Image 1.5がLM Arenaスコア1264で首位を獲得するなど技術進化は続くが、YouTube上での「新鮮さ」は薄れている。
- **主要チャンネル:**
  - KEITO【AI&WEB ch】（登録者3万人超、Midjourney/ChatGPT系）
  - ZIG（画像生成AI特化、登録者1万人超）
  - にゃんたのAIチャンネル（AI VTuber系）
- **人気動画の傾向:**
  - 「2026年最新 画像生成AI比較・ランキング」系が定番
  - 無料ツール5選などの「まとめ系」が再生を稼ぐ
  - Midjourneyのチュートリアル動画は英語圏で依然として大量に投稿されている
- **穴場テーマ:**
  - GPT Image 1.5を使った商用デザインワークフロー
  - AI画像生成 x 印刷物（名刺・ポスター）など実務寄りの活用法
  - Fluxなど新興モデルの日本語チュートリアル（まだ少ない）

---

### 2. AI動画生成（Sora, Runway, Kling, Veo等）

- **盛り上がり: S** -- 2026年で最も活発なジャンルの一つ。Sora2は2026年3月にサービス終了したが、Kling 2.6、Veo 3.1、Runway Gen-3が激しく競合。映像と音声の同時生成（Kling 2.6）など技術革新が加速。
- **主要チャンネル:**
  - AI動画生成系のまとめチャンネルが急増中
  - ムービーインパクト（プロ目線のAI映像クリエイティブ解説）
  - 各ツール公式チャンネル
- **人気動画の傾向:**
  - 「全ての動画生成AIにランク付けしてみた」系の比較動画が高再生
  - Kling vs Veo のシネマティック比較が話題
  - 「AIで動画を作ってYouTubeに投稿する完全ガイド」系の初心者向けが安定
  - Seedance 2.0など新ツールの速報レビュー
- **穴場テーマ:**
  - Sora2終了後の代替ワークフロー解説
  - AI動画 x リップシンク（Kling 2.6の音声同時生成）の実践
  - YouTube Shorts向けのAI動画制作ワークフロー（Reimagine機能との連携）
  - 企業向けのAI動画活用事例

---

### 3. AI音楽・音声（Suno, Udio, ElevenLabs等）

- **盛り上がり: A** -- SunoとUdioが市場をリード。日本語ボーカルの品質が飛躍的に向上し、YouTube上ではAI生成のローファイBGMチャンネルが急増。チャンネル「what is ?」は登録者13万人超、最人気動画200万再生超。
- **主要チャンネル:**
  - AI音楽部（AI音楽特化チャンネル）
  - what is ?（全曲AI生成のローファイ音楽チャンネル、登録者13万人超）
  - ノーブランド社（AI音楽チャンネルの運営ノウハウ公開）
- **人気動画の傾向:**
  - AI生成ローファイ/チル系BGM配信が圧倒的
  - 「Suno x YouTubeで月4万円収益化」系のノウハウ
  - AI音楽の収益化ポリシー解説
  - 商用利用可能なAI音声ツール比較
- **穴場テーマ:**
  - AI音楽 x YouTube BGMチャンネル運営の実践ノウハウ
  - ElevenLabsを使ったポッドキャスト/オーディオブック制作
  - AI音声ナレーション x 教育コンテンツ
  - 著作権訴訟の最新動向と安全な使い方（大手レーベル訴訟継続中）

### 4. ChatGPT / Claude / Gemini 活用術

- **盛り上がり: S** -- ChatGPT週間アクティブユーザー9億人突破。Claude Mythosの登場など話題が絶えない。日本語チャンネルも充実。
- **主要チャンネル:**
  - mikimiki web スクール（AIニュースの翌日配信、バランスの良い解説）
  - いけともch（ChatGPT/AI/リモートワーク系）
  - AI大学（毎日のAI情報まとめ）
  - chaen（AI特化チャンネル）
  - Akiyama Yuta / AI活用術（登録者2.9万人超）
- **人気動画の傾向:**
  - 「ChatGPT使い方完全ガイド」系は常に安定
  - Claude完全解説（20以上の便利機能解説）
  - YouTube動画要約ツール/Chrome拡張の紹介
  - プロンプトエンジニアリング実践
- **穴場テーマ:**
  - Claude Code/Claude Managed Agentsの日本語解説（まだ少ない）
  - Gemini x Googleサービス連携の実践活用
  - 業種別（医療/法律/教育）のAI活用術
  - ChatGPT x YouTube台本作成の具体的ワークフロー

### 5. AIコーディング（Cursor, Claude Code, GitHub Copilot等）

- **盛り上がり: S** -- 「使うかどうか」ではなく「どう使い分けるか」の時代に突入。Claude Codeが開発者の46%から「最も好き」と評価され、注目度が急上昇中。Gizmodoでは「文系が10ヶ月AIコーディングやってみた」記事が話題に。
- **主要チャンネル:**
  - 英語圏が中心で、日本語チャンネルはまだ少数
  - Cursor入門系の日本語動画は増加傾向
  - AIコーディング講座チャンネル（2026年の新規開設増）
- **人気動画の傾向:**
  - 「Cursor vs Claude Code vs GitHub Copilot 比較」系が最も人気
  - 「Cursor入門 初心者OK AI駆動開発」系のチュートリアル
  - 「非エンジニアがAIでアプリを作ってみた」体験談
  - AIコーディングツール5選の選び方ガイド
- **穴場テーマ:**
  - Claude Codeの日本語チュートリアル（英語圏では多いが日本語は極めて少ない）
  - Windsurf、Devinなど新興ツールの日本語レビュー
  - 「文系/非エンジニア向け」AIコーディング入門シリーズ
  - 実際のプロジェクトでのAIコーディング活用ドキュメンタリー

### 6. AIビジネス・副業

- **盛り上がり: A** -- 「AI副業で月5万円」系のコンテンツが大量に存在。ただし2026年はAI副業の「コモディティ化」が始まっており、差別化が課題。YouTubeのAIスロップ対策強化により、AI丸投げ系の収益化は困難に。
- **主要チャンネル:**
  - あべむつき（AI活用法マガジン系）
  - AI FREAK（最新AIツール紹介）
  - ビジネス+IT系メディアチャンネル
- **人気動画の傾向:**
  - 「2026年最新 AI副業ランキングTOP10」系が高再生
  - 「ChatGPT副業で不労所得」系の煽り系タイトル（ただしYouTubeの規制強化傾向）
  - 「AI動画で不労所得は本当か？」検証系が増加
  - RPM/CPM分析を含む「現実的な収益化」解説
- **穴場テーマ:**
  - BtoB向けAIコンサル（RPM 500-1000円以上と高単価）
  - AI x 特定業界（不動産/飲食/美容）のDX事例
  - 「人間 x AI協働スタイル」の具体的ワークフロー公開
  - AI副業の失敗談/現実レポート（信頼を得やすい）

### 7. AIニュース・最新情報

- **主要チャンネル:**
  - mikimiki web スクール（速報性が高い）
  - chaen（AI特化ニュース）
  - AI大学（毎日のまとめ）
  - AI QUEST（深掘り系、Claude Mythos特集など）
  - 今日のAIニュースまとめ（プレイリスト形式で毎日更新）
- **人気動画の傾向:**
  - 「今週/今日のAIニュースまとめ」定期配信が安定
  - 大型ニュース（資金調達、新モデル発表）の速報解説
  - 「注目AIニュース15選/19選」などまとめ系
  - YouTube自体のAI新機能解説
- **穴場テーマ:**
  - 海外AIニュースの日本語速報（英語圏との時差を埋める）
  - AIスタートアップ投資/ビジネス視点のニュース分析
  - YouTube x AI機能（サムネ自動翻訳、Reimagine等）の先行レビュー
  - 週刊/月刊の定期ニュースレター形式チャンネル

### 8. AIエージェント

- **主要チャンネル:**
  - 日本語専門チャンネルはまだ非常に少ない（最大の狙い目）
  - Google Cloud公式（エージェントAI/生成AIプレイリスト）
  - AI QUEST系（深掘り解説）
  - Anthropic公式のエージェントパターン解説動画
- **人気動画の傾向:**
  - 「AIエージェントって結局なに？非エンジニア向け解説」が高需要
  - 「AIエージェントの勝ち筋 2026年」などビジネス視点
  - Anthropicのエージェントパターン解説
  - 「AI Agentに6週間YouTubeチャンネルを任せてみた」など実験系
- **穴場テーマ:**
  - AIエージェントの日本語入門シリーズ（競合が極めて少ない）
  - Claude Managed Agents / ChatGPT Workspace Agents の実践チュートリアル
  - バックオフィス業務自動化のAIエージェント活用事例
  - ノーコードでAIエージェントを構築するハンズオン

## まとめ: 今最も狙い目のジャンルTOP3

### 第1位: AIエージェント -- おすすめ度 S

**理由:** 2026年最大の技術トレンドであり、Google、OpenAI、Anthropicが一斉にエージェント機能をリリースしているにもかかわらず、日本語でのYouTube解説コンテンツが圧倒的に不足している。「盛り上がりS x 競合B」という最高の参入条件。非エンジニア向けの分かりやすい解説、具体的な業務自動化事例、ハンズオン形式のチュートリアルを提供できれば、先行者利益を大きく取れる。

### 第2位: AIコーディング -- おすすめ度 S

**理由:** Claude Codeが開発者人気46%を獲得し、「文系でもAIでアプリが作れる」という流れが加速中。日本語のClaude Code/Cursor/Windsurf解説動画は英語圏と比較して圧倒的に少なく、ブルーオーシャン状態。特に「非エンジニア向けAIコーディング入門」は需要が高いが供給が追いついていない。技術系はRPM 300-600円と広告単価も高い。

### 第3位: AI動画生成 -- おすすめ度 A

**理由:** Sora2の終了、Kling 2.6の音声同時生成、Veo 3.1の登場など、ツールの入れ替わりが激しく、常に「最新比較」の需要がある。YouTubeの「Reimagine」機能（Veo搭載のShorts生成）との連携解説など、YouTube自体のAI機能と絡めたコンテンツは差別化しやすい。競合は増えているが、プロ品質の映像比較や実務ワークフロー解説で差別化可能。

---

### 補足: 避けるべきジャンル

- **AI画像生成（単体）:** 成熟期に入り競合飽和。やるなら「AI画像 x 実務活用」など切り口を絞る必要あり。
- **AI副業（煽り系）:** YouTubeのAIスロップ対策強化により「不労所得」系は収益化リスクが高い。やるなら「現実的な検証レポート」路線が安全。
