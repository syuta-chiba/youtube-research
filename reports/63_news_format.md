## 2. 各チャンネルの構成・尺・更新頻度の詳細分析

### 共通する構成パターン

```
【典型的な週刊AIニュースまとめの構造】

0:00 - 0:15  フック（最もインパクトのあるニュースを冒頭に）
0:15 - 0:30  イントロ（チャンネル名・番組名・週の概要）
0:30 - 3:00  トップニュース #1（最重要）
3:00 - 5:30  トップニュース #2
5:30 - 8:00  トップニュース #3
8:00 - 12:00 中規模ニュース 3-5本（各1-2分）
12:00 - 14:00 ツール・サービス紹介
14:00 - 15:00 まとめ・来週の注目ポイント + CTA
```

### フォーマット別の特徴

#### A. 「ニュースカウントダウン型」（Matt Wolfe式）
- タイトル例: 「29 Biggest AI Stories You Missed This Week」
- 数字をタイトルに入れることでクリック率向上
- 各ニュースを1-2分で手早く紹介
- 画面: ニュースサイトのスクリーンショット + 顔出しワイプ

#### B. 「デイリーブリーフ型」（Wes Roth式）
- 毎日15-20分、その日の最重要ニュース2-3本を深掘り
- 速報性が武器
- ポッドキャスト的な語り口

#### C. 「論文解説型」（Two Minute Papers式）
- 1本の論文・技術を深く解説
- 独自のキャッチフレーズで差別化
- ビジュアル・アニメーション重視

#### D. 「ポッドキャスト同時配信型」（AI Daily Brief式）
- YouTube + Spotify + Apple Podcastsの3面展開
- 音声だけでも成立する構成
- 通勤時間帯のリスナー獲得

### 最適な動画尺

- **12-15分**: テック系で最もエンゲージメントが高い尺（25-34歳プロフェッショナル層のベスト）
- **5分以下**: 高い完走率（60-70%）だが広告収益が低い
- **20分超**: コアファン向け。初期チャンネルには不向き

## 3. リテンション（視聴維持率）の戦略

### ベンチマーク
- 良好: 40-60%
- 優秀: 60%以上（5分以下の動画）
- 50%以上: 長尺動画で合格ライン

### 最重要ポイント

1. **最初の15秒が全て**: 30-40%の視聴者が最初の30秒で離脱。冒頭で「結果」を見せてから「過程」を説明する
2. **中盤の再エンゲージ**: 10分超の動画では55-65%地点で15%の二次離脱が発生。ペース変化やビジュアル切替が必要
3. **コメント返信**: 公開後2時間以内に50件以上のコメント返信でリーチが15-20%向上
4. **リテンション10%改善 = インプレッション25%増**: アルゴリズムへの直接的シグナル

## 4. サムネイル戦略（2026年最新）

### トレンド
- **「Proof of Human」**: AI生成画像より「本物の人間の表情」が22%高いCTR満足度
- **ハイコントラスト**: オレンジ・赤・黄色の高コントラスト配色
- **テキストは3語以内**: 多すぎるテキストはモバイルで視認不可
- **ハイブリッドワークフロー**: AI背景生成 + 手動の顔オーバーレイが最適解
- **モバイル最適化**: 小さいサムネイルでも読めるデザインが必須

### AIニュース系サムネイルの定番パターン
1. 驚いた表情の顔 + AIツールのロゴ + 短い煽り文
2. ニュースの主要人物（Sam Altman等）+ インパクトワード
3. 数字強調（「29 Stories」「Top 10」）+ グラデーション背景

## 5. 日本語でのAIニュース番組の状況

### 主要チャンネル

| チャンネル | 特徴 |
|---|---|
| **今週のAIニュースまとめ**（プレイリスト） | 週次でAIニュースを15-20本ピックアップ。タイトル例: 「注目AIニュース16選〜Claude Cowork Windows対応、GPT 5.3 Codex Spark...」 |
| **AI大学【AI&ChatGPT最新情報】** | 週4-5本更新。ChatGPT中心の情報まとめ |
| **いけともch** | ChatGPT・最新AIツール・リモートワークツールを解説。IT初心者向け |
| **AI QUEST** | AI研究者・今井翔太氏らが出演。OpenAIの評価額やAI開発競争など深掘り |

### 日本語市場の特徴
- 英語圏と比較して**週刊まとめ形式の定期番組**が少ない
- 単発のニュース動画が多く、シリーズ化されたフォーマットが確立されていない
- **Ledge.ai**などのWebメディアが強く、YouTube専門チャンネルはまだ発展途上
- **チャンス**: 英語圏のフォーマットを日本語で再現する余地が大きい

## 6. emperor_ch「週刊AIニュース」立ち上げプラン

### 番組コンセプト

**番組名案**:
- 「今週のAI、全部わかる」
- 「週刊AI速報」
- 「AIウィークリー by emperor」

**ポジショニング**: Matt Wolfe式の「週刊まとめ」を日本語で展開。英語圏の情報を日本語話者にいち早く届ける。

### フォーマット設計

```
【推奨フォーマット】
更新頻度: 週1回（毎週日曜 or 月曜公開）
動画尺: 12-15分（最適ゾーン）
構成: ニュースカウントダウン型
Shorts: 各ニュースを60秒に切り出し、週3-4本投稿
```

### 運用スケジュール（週間）

| 曜日 | タスク |
|---|---|
| 月-金 | ニュースソース巡回・Notionにストック |
| 土 | 台本作成（5-7本のニュースを選定） |
| 日午前 | 収録・編集 |
| 日午後 | 本編公開 |
| 月-水 | Shorts切り出し・公開（各日1本） |

### 成長戦略

1. **Phase 1（Month 1-3）**: 週1本の本編 + 週3本のShorts。フォーマット固定・認知獲得
2. **Phase 2（Month 4-6）**: ニュースレター連携（概要欄からメルマガ登録誘導）
3. **Phase 3（Month 7-12）**: ポッドキャスト同時配信（Spotify/Apple）。ゲスト出演開始

### KPI目標

| 期間 | 登録者 | 平均視聴回数 | リテンション |
|---|---|---|---|
| 3ヶ月 | 500 | 200-500 | 40%以上 |
| 6ヶ月 | 2,000 | 1,000-3,000 | 45%以上 |
| 12ヶ月 | 10,000 | 5,000-10,000 | 50%以上 |

```
===========================================
週刊AIニュース by emperor_ch
第1回 台本テンプレート
===========================================

【0:00-0:10 フック】
「今週、OpenAIが〇〇を発表しました。
これ、控えめに言ってゲームチェンジャーです。
今週のAIニュース、全部まとめます。」

【0:10-0:30 オープニング】
「こんにちは、emperor_chです。
このチャンネルでは毎週、
AIの最新ニュースをまとめてお届けします。
今週は〇本のニュースを取り上げます。
それでは行きましょう。」

---

【0:30-3:30 ニュース #1（トップニュース）】
■ 見出し: [ニュースタイトル]
■ 何が起きた: [事実を30秒で]
■ なぜ重要: [影響・意味を1分で]
■ emperor的見解: [自分の意見を30秒で]
■ 画面: ニュースサイトのスクショ / デモ動画

---

【3:30-5:30 ニュース #2】
■ 同上の構造

---

【5:30-7:30 ニュース #3】
■ 同上の構造

---

【7:30-10:30 クイックニュース 4-6本】
「ここからはサクサクいきます。」
■ 各ニュース30-45秒
■ 見出し → 一言解説 → 次へ
■ テンポ良く画面切替

---

【10:30-12:00 今週のツール紹介（1-2個）】
「今週見つけた面白いAIツールを紹介します。」
■ ツール名 → 何ができるか → デモ → 所感
■ 概要欄にリンク

---

【12:00-13:00 来週の注目ポイント】
「来週はGoogleの開発者会議があるので、
大きな発表がありそうです。」

---

【13:00-13:30 エンディング + CTA】
「今週のAIニュースは以上です。
毎週〇曜日に更新しているので、
見逃したくない方はチャンネル登録と
通知をオンにしてください。
それではまた来週。」

===========================================
```

### 台本作成のポイント

1. **1ニュースにつき最大3分**: それ以上は別動画で深掘り
2. **「なぜ重要か」を必ず入れる**: 事実の羅列だけでは差別化できない
3. **自分の意見を入れる**: 「emperor的見解」が独自性になる
4. **テンポ**: クイックニュースセクションでペース変化を作り、中盤離脱を防ぐ
5. **最初の10秒**: 最もインパクトのあるニュースの結論を先出し

## 8. ニュースソースの集め方・自動化

### Tier 1: 必読ソース（毎日チェック）

| カテゴリ | ソース |
|---|---|
| **総合AI** | The Verge AI, TechCrunch AI, Ars Technica AI |
| **研究** | arXiv (cs.AI, cs.CL), Papers With Code |
| **企業公式** | OpenAI Blog, Anthropic Blog, Google AI Blog, Meta AI Blog |
| **X/Twitter** | @sama, @daborenstein, @kaborav, @emaborowitz, @maborosmith |
| **Reddit** | r/MachineLearning, r/artificial, r/LocalLLaMA |

### Tier 2: 週次チェック

| カテゴリ | ソース |
|---|---|
| **ニュースレター** | The Batch (Andrew Ng), Import AI, TLDR AI, AI Weekly |
| **ポッドキャスト** | Last Week in AI, The AI Daily Brief |
| **日本語** | Ledge.ai, AI-SCHOLAR, ITmedia AI+ |

### 自動化ツールスタック

```
【推奨自動化構成】

1. RSS集約
   - Feedly Pro（AIフィード一括管理）
   - Inoreader（高度なフィルタリング）

2. 自動収集・要約
   - auto-news (GitHub: finaldie/auto-news)
     → RSS/X/YouTube/Redditから自動収集
     → LLM（ChatGPT/Gemini）で要約
   - AI News Aggregator (GitHub: AKAlSS/AI-News-Aggregator)
     → RSSから日次ダイジェスト生成 → Notionに自動投稿

3. ニュースクリッピング
   - Notion Web Clipper → 気になる記事をNotionDBに保存
   - Readwise Reader → ハイライト自動同期

4. 台本生成補助
   - Claude / ChatGPTに週のクリッピングを入力
   - 「週刊AIニュースの台本テンプレートに沿って構成して」
   - 出力を手動で編集・ファクトチェック

5. 動画制作
   - 録画: OBS Studio / ScreenFlow
   - 編集: DaVinci Resolve / Premiere Pro
   - サムネイル: Canva + 実写素材
   - 字幕: Whisper → .srt自動生成
```

### 週間ワークフロー例

```
月-金: Feedlyで自動収集 → Notionに蓄積（自動）
土AM: Notionから今週のトップニュースを選定（30分）
土PM: Claude/ChatGPTで台本ドラフト生成 → 手動編集（1-2時間）
日AM: 収録（30-45分）→ 編集（1-2時間）
日PM: サムネイル作成（15分）→ アップロード → 公開
月-水: Shorts切り出し・投稿（各15分）
```
