## 当たり動画（再生数が高いと推定される動画）

### 1. たった１時間でAIを使ってアプリ開発ができるなんて信じられません・・・【bolt.new / claude / cursor(Composer)を利用】
- **推定再生数**: 10万～30万回（AI開発系で最もバズりやすいテーマ）
- **なぜ伸びたか**:
  - 「たった１時間」という具体的な時間の提示で衝撃を与えている
  - 「信じられません」という感情的なフックがCTRを上げている
  - bolt.new / claude / cursor という2024年末の最旬ツール3つを同時にカバー
  - 「非エンジニアでもできる」という暗黙のメッセージがターゲットを広げている
  - 投稿タイミングがbolt.newの爆発的な話題性と一致
- **企画のエッセンス**: 「短時間 × 複数ツール × 驚きの結果」の組み合わせ

### 2. 【Cursor入門】初心者OK！AIを使ってアプリ開発する方法を全て解説します ~AI駆動開発入門~
- **推定再生数**: 5万～15万回
- **なぜ伸びたか**:
  - Cursor検索需要が爆発的に伸びた時期（2025年初頭）に投稿
  - 「初心者OK」で裾野を広げている
  - 「全て解説」でワンストップの価値を訴求
  - 「AI駆動開発入門」というSEO的に強いサブタイトル
  - 長尺の網羅的コンテンツはYouTubeのアルゴリズムに有利
- **企画のエッセンス**: 「初心者OK × 網羅性 × トレンドツール」

### 3. 【完全版】これ一本で「バイブコーディング」の全てが学べます【AI駆動開発/Cursorを利用】

- **推定再生数**: 1,000～5,000回
- **なぜ伸びなかったか**:
  - 会社紹介・事業説明は視聴者にとって価値が薄い
  - 「事業概要」というタイトルは視聴者の関心を引かない
  - 教育コンテンツではなく営業コンテンツに見える
  - 検索需要がほぼゼロ

### 2. 個別のノーコードツール解説（bubble、Adaloなど旧世代ツール）
- **推定再生数**: 3,000～1万回
- **なぜ伸びなかったか**:
  - 2024年以降、AI駆動開発にトレンドがシフト
  - bubbleやAdaloの検索ボリュームは下降傾向
  - 競合が多く差別化が難しい
  - ツールが古く感じられる

### 3. 開発費用・見積もり系の解説動画
- **推定再生数**: 5,000～2万回
- **なぜ伸びなかったか**:
  - BtoB寄りのテーマで視聴者層が限定的
  - 「費用」「見積もり」は動画より記事で読みたい情報
  - エンタメ性が低く、リテンション率が下がる
  - サムネイルで魅力を出しにくいテーマ

### 4. 会社のメディア記事と連動した補足動画
- **推定再生数**: 1,000～5,000回
- **なぜ伸びなかったか**:
  - 記事の補足的な位置づけでYouTube単体での価値が低い
  - タイトルが記事寄りでYouTube的な引きがない
  - YouTube検索・おすすめに乗りにくい構造

## 当たり vs ハズレの差は何か

### タイトルの違い
| 当たりパターン | ハズレパターン |
|---|---|
| 「たった○○で」「信じられません」など感情フック | 「事業概要」「○○とは」など説明的 |
| 【完全版】【入門】など学習価値を明示 | カテゴリが曖昧、何が学べるか不明 |
| 具体的ツール名（Cursor, bolt.new, Dify） | 抽象的な概念のみ |
| 「初心者OK」「ゼロから」で敷居を下げる | ターゲットが不明確 |
| 数字を含む（1時間、完全版） | 数字なし |

### テーマの違い
| 当たるテーマ | ハズレるテーマ |
|---|---|
| 最新AIツールの使い方・レビュー | 会社紹介・事業説明 |
| バイブコーディング・AI駆動開発 | 旧世代ノーコードツール単体 |
| 「非エンジニアでもできる」系 | 開発費用・見積もり等BtoBコンテンツ |
| 起業・副業と絡めたアプリ開発 | 技術的すぎる深掘り |
| ツール比較・対決 | 単一ツールの淡々とした説明 |

### サムネの違い（推定）
| 当たりパターン | ハズレパターン |
|---|---|
| 人物（山口さん）+ 驚き表情 | テキストのみ・図解のみ |
| ツールのロゴを大きく配置 | 小さい文字が多い |
| 「衝撃」「最強」「完全版」等のパワーワード | 淡々とした説明的テキスト |
| 明るい・コントラストが高い配色 | 地味な色合い |

### フォーマットの違い
| 当たりパターン | ハズレパターン |
|---|---|
| 長尺（30分～1時間以上）の完全版 | 短い説明動画（5-10分） |
| 画面共有しながらの実演・ライブコーディング | スライド説明のみ |
| 「ゼロから完成まで」の一気通貫 | 部分的な解説 |
| Before/After（何もない→アプリ完成）の構造 | 機能説明の羅列 |

## 伸びるパターンまとめ

### 鉄板テーマ
1. **最新AIツールの初心者向け完全ガイド** - Cursor、bolt.new、Lovable、Difyなど
2. **バイブコーディング（AI駆動開発）の実践** - 実際にアプリを作る過程を見せる
3. **「非エンジニアが○○を作ってみた」系** - 驚きの結果を見せる
4. **AIツール同士の比較・対決** - Cursor vs Windsurf、bolt.new vs Lovableなど
5. **起業・副業×アプリ開発** - ビジネス的なモチベーションに訴求

### 鉄板タイトル構造
1. **【完全版】○○の全てが学べます【△△を利用】** - 網羅性 + 具体的ツール名
2. **たった○分/○時間で○○ができるなんて信じられません** - 時間 + 驚き
3. **【○○入門】初心者OK！○○する方法を全て解説します** - 敷居を下げる + 網羅性
4. **【○○の上位互換!?】超優秀すぎる○○を徹底レビュー** - 比較 + 強い形容詞
5. **【結論】○○が最強すぎました...** - 断定 + 余韻

### 鉄板フォーマット
1. **長尺完全ガイド（30分～1時間）**: ゼロから完成まで全て見せる
2. **ライブコーディング実演**: 実際に画面を共有しながらアプリを作る

4. **比較動画**: 複数ツールを同じ条件で比較

## 総合分析・結論

### walkers-developmentの強み
1. **SEO/検索流入に最適化されたタイトル設計**: ツール名 + 入門/完全版で検索需要を確実に拾う
2. **記事メディアとの連動**: walker-s.co.jp の記事とYouTube動画を相互送客
3. **開発会社としての信頼性**: 300件以上の実績が権威性を裏付け
4. **トレンドツールへの素早い対応**: bolt.new、Dify、バイブコーディングなど話題のツールを素早くカバー
5. **ターゲットの明確さ**: 経営者/起業家/新規事業担当者という高単価ターゲット

### walkers-developmentの弱み
1. **BtoB寄りのコンテンツが多い**: 一般視聴者に刺さりにくい動画もある
2. **会社PR色が出る動画は伸びない**: 事業概要系は再生数が低い
3. **エンタメ性が低い**: 淡々とした解説が多く、キャラクター的な魅力は弱い
4. **ショート動画が少ない（推定）**: ショート経由の新規流入が限定的

### emperor_chが差別化できるポイント
1. **個人開発者としてのリアルな体験談**: 会社ではなく個人の視点で語る
2. **エンタメ性の付加**: 驚き、失敗、試行錯誤などドラマ性を加える
3. **より実践的な内容**: 実際に収益化したアプリ、実際の開発過程を見せる
4. **Claude Code特化**: Walkersが広くカバーする中で、Claude Code専門として深掘り
5. **ショート動画の活用**: AIツールの「30秒で分かる」系ショートで認知拡大
