## 海外で爆発的に伸びているが日本にまだないフォーマット

### 1. AI vs AI ディベート（AI同士を戦わせる討論ショー）
- **海外での事例**: 「Proof You Are the Best AI | AI vs AI Debate」などの動画が急増中。Claude vs GPT vs Gemini を同じ議題で対決させ、視聴者投票で勝敗を決めるフォーマット。DebateAI等の専用ツールも2026年に7つ以上登場
- **なぜ伸びているか**: 「どのAIが最強か」は永遠の関心事。対決構造は視聴者のコメント・投票を誘発し、エンゲージメント率が通常動画の3〜5倍。毎週テーマを変えられるのでシリーズ化しやすい
- **日本語でやる場合のアレンジ案**: 日本の時事ネタ（少子化、働き方改革、教育改革）でAI同士にディベートさせる。「AI国会」のようなコンセプトで政策議論させるのも面白い
- **タイトル案3つ**:
  1. 「ChatGPT vs Claude vs Gemini 本気ディベート｜少子化問題をAIに解決させたら衝撃の結論」
  2. 「AI同士がガチ喧嘩｜"日本の教育は終わってる"を3大AIに議論させた結果」
  3. 「AI国会開催｜5つのAIに日本の未来を討論させたら人間より的確だった」

### 2. Vibe Coding ライブチャレンジ（AIだけでアプリを作る生配信）
- **海外での事例**: 「Can We Build an AI Tutor in an Hour? Live Coding Challenge!」等、Claude Code / Cursor / Replit を使い1時間以内にアプリを完成させるライブ配信が急増。Vibe Coding市場は$4.7B（2025）→ $12.3B（2027予測）
- **なぜ伸びているか**: リアルタイムの緊張感、AIの実力が丸見え、視聴者がチャットでアイデアを出せるインタラクティブ性。非エンジニアでも「こんな簡単にアプリが作れるのか」と驚く
- **日本語でやる場合のアレンジ案**: 「視聴者のアプリアイデアを1時間でAIに作らせるライブ」「非エンジニアの芸人/タレントがAIだけでアプリを作る挑戦」
- **タイトル案3つ**:
  1. 「プログラミング経験ゼロの僕がAIだけで1時間でアプリを作る【ライブ】」
  2. 「視聴者のアイデアをAIで即アプリ化｜Vibe Coding生チャレンジ」
  3. 「Claude Codeに全部任せたら何分でアプリ完成する？タイムアタック」

### 3. AI歴史人物インタビュー（偉人にAIで喋らせる）
- **海外での事例**: 「Einstein explaining crypto」等、AI生成の歴史人物が現代のトピックを解説する動画が急増。@timetravellerpov は黒死病POV動画で1800万再生、チェルノブイルPOV動画で2180万再生を達成
- **なぜ伸びているか**: 教育 x エンターテインメントの最強コンボ。没入感が高く、シェアされやすい。POVフォーマットとの相性が抜群
- **日本語でやる場合のアレンジ案**: 織田信長にビットコインを説明させる、坂本龍馬に現代のスタートアップを評価させる、紫式部にSNSを使わせる等。日本史の偉人は海外とは異なる独自コンテンツになる
- **タイトル案3つ**:
  1. 「織田信長にChatGPTを使わせたら天下統一の新戦略を考え始めた」
  2. 「坂本龍馬が現代の日本を見たら何を変える？AIで本人に聞いてみた」
  3. 「紫式部にInstagramを教えたら"いいね"の本質を語り始めた【AI再現】」

### 4. AIティアランキング動画（AI製品をランク付けバトル）
- **海外での事例**: 2026年のエンゲージメント最強フォーマットTOP6に選出。AIツールをS/A/B/C/Dティアに分類する動画が大量発生。視聴者がコメント欄で激論になりエンゲージメント率が突出
- **なぜ伸びているか**: 主観的なランキングは「異議あり！」を誘発し、コメント数が爆増。毎月新ツールが出るので更新性が高い。サムネイルがキャッチーで高CTR
- **日本語でやる場合のアレンジ案**: 日本語対応AIツールに特化、用途別（文章/画像/動画/音楽/コーディング）でティアランキング
- **タイトル案3つ**:
  1. 「2026年AIツール格付けチェック｜S〜Dランクで本音レビュー【永久保存版】」
  2. 「AIコーディングツール頂上決戦｜Claude Code vs Cursor vs Copilot ティアランキング」
  3. 「画像生成AI 全15種をガチ比較｜Sランクはどれだ？【2026年最新】」

### 5. 30日AIチャレンジ（毎日AIを使って成果を出すドキュメンタリー）
- **海外での事例**: Ed Dale「AI 30 Day Challenge」、Coursiv「28-Day AI Challenge」、「$215M AI CEO: How I'd Build a Profitable AI Startup in 30 Days (2026 Playbook)」等。ドキュメンタリー+教育のハイブリッドが人気
- **なぜ伸びているか**: 連続コンテンツで視聴者のリテンション率が高い。「自分もやってみよう」という参加型の空気。ビフォーアフターが明確
- **日本語でやる場合のアレンジ案**: 「30日間AIだけで副業して月収いくら稼げるか」「AIだけで30日間英語学習したらTOEIC何点上がるか」
- **タイトル案3つ**:
  1. 「30日間AIだけで副業チャレンジ｜Day1→30の収益を全公開」
  2. 「AIに全部任せて30日でYouTubeチャンネル1万人達成できるか」
  3. 「30日間AIだけで英語学習したらTOEIC何点上がる？【ガチ検証】」

### 6. AI Faceless ホラーナレーション（顔出しなしAI怪談チャンネル）
- **海外での事例**: 2026年エンゲージメント6大フォーマットの一つ。AI生成ビジュアル + AI音声ナレーションで怪談・都市伝説を語る。Facelessコンテンツがバイラル動画の30%を占める時代に
- **なぜ伸びているか**: 制作コストが極めて低い（AI画像+AI音声のみ）。ホラーは言語を超えて需要がある。寝る前に聴く「ながら視聴」需要
- **日本語でやる場合のアレンジ案**: 日本は怪談文化が世界最強。AI映像で「本当にあった怖い話」を映画レベルのビジュアルで再現
- **タイトル案3つ**:
  1. 「AIが描く日本の怖い話｜絶対に一人で見ないでください【都市伝説】」
  2. 「実話怪談をAIで完全映像化｜あなたの町にも潜む恐怖」
  3. 「深夜2時に聴く怪談AI｜眠れなくなる実話10選」

### 7. AI音楽プロデュース（テキストから楽曲を作るチュートリアル）
- **海外での事例**: SunoとUdioが民主化の中心。テキストプロンプトから30秒でフル楽曲（ボーカル+楽器+プロダクション）が生成可能に。全曲AI作成の音楽系YouTubeチャンネルが人気を博す
- **なぜ伸びているか**: 音楽制作の参入障壁が劇的に下がった。「自分の曲が作れる」感動。EU AI Actで2026年8月からAI音楽のラベリング義務化が話題に
- **日本語でやる場合のアレンジ案**: J-POP/アニソン/ボカロ風楽曲をAIで作るチュートリアル。「AIで作ったボカロ曲をニコニコに投稿してみた」系
- **タイトル案3つ**:
  1. 「音楽経験ゼロがAIだけでJ-POPを作ってみた｜Suno完全チュートリアル」
  2. 「AIで作ったアニソンがプロの曲と区別つかない件【聴き比べ】」
  3. 「AIボカロ曲を投稿したら何再生いく？｜制作から投稿まで全解説」

### 8. Claude Code / AIエージェント構築チュートリアル
- **海外での事例**: 「800+ hours of Learning Claude Code in 8 minutes」「Claude Code Now Works While You Sleep (Routines Tutorial 2026)」等が急増。「Build Your First AI Agent」系動画が毎週のようにアップロード
- **なぜ伸びているか**: AIエージェントが「知る人ぞ知る」から「マスト」に変わった2026年。実務直結で企業の研修需要もある。Claude Codeのルーティン機能（クラウドで自動実行）が最新注目トピック
- **日本語でやる場合のアレンジ案**: 日本語での体系的Claude Codeチュートリアルは極めて少ない。「寝ている間にClaude Codeが仕事をしてくれる」等の切り口
- **タイトル案3つ**:
  1. 「Claude Codeを寝てる間に働かせる方法｜Routines完全解説【2026年最新】」
  2. 「AIエージェントを30分で作る｜Claude Code初心者チュートリアル」
  3. 「もうコード書かなくていい｜Claude Codeで業務を完全自動化する方法」

### 英語圏で成功しているフォーマットパターン
- **"X in 100 seconds"**: Fireship型の超圧縮解説 → 日本にはこの密度の解説者がいない
- **Weekly AI News Roundup**: Matt Wolfe型 → 日本では「mikimiki web スクール」が近いが深さが不足
- **"I tested every..."型 比較レビュー**: 全ツールを実際に試して比較 → 日本語で網羅的にやる人が少ない
- **Live Build Challenge**: リアルタイムでAIアプリを構築 → 日本語でのライブコーディングは極めて少数

## 韓国のAI YouTube動向

### 韓国独自のトレンド
1. **AI食べ放題（モッパン）動画**: 朝鮮時代の中年男性がご飯とキムチを食べるAI生成モッパンがInstagramでバイラル化。AIで食文化を再解釈するジャンルが急成長
2. **AI Faceless Creator 急増**: ソン・ミニョンのように元会社員がAIツールだけでインスタ2万フォロワーのデジタルクリエイターに転身。「普通の人がAIクリエイターになる」ストーリーが共感を呼ぶ
3. **AI ASMR / スライム動画**: ガラスの果物・野菜を切るAI生成ASMR動画がTikTokでバイラル化。韓国発のAI ASMRフォーマットが世界に拡散
4. **AIスロップ（低品質AI動画）の大量発生**: 韓国のトレンドAIスロップチャンネルは累計84.5億再生。品質の低いAI大量生産コンテンツが社会問題化
5. **Veo 3 / Soraの活用**: AIビデオ生成ツールを使った映像制作が一般ユーザーにまで浸透。「犬が韓国語でインタビューに答える」「溶岩の中を泳ぐ」等の非現実映像が人気

### 韓国から学べるポイント
- 食文化 x AI は日本でもそのまま応用可能（ラーメン、寿司、居酒屋のAI映像）
- 「一般人がAIクリエイターに転身」ドキュメンタリーは日本でも需要大
- AI ASMR は日本のASMRコミュニティに新風を吹き込める

## 「日本語で最初にやれば勝てる」企画リスト20個

### カテゴリA: フォーマット系（誰もやっていない形式）

1. **AI国会ディベート** - ChatGPT / Claude / Gemini / DeepSeek に政治家役をやらせて国会討論。毎週テーマを変えてシリーズ化。視聴者投票で「最優秀答弁AI」を決定
2. **100秒AI解説（Fireship日本語版）** - 毎日1本、AIトピックを100秒で超高密度に解説。日本には「Fireship的な」テンポのチャンネルが存在しない
3. **AI偉人インタビューシリーズ** - 毎週1人の日本史偉人をAIで再現し、現代社会について語らせる。織田信長 x 起業論、聖徳太子 x マルチタスク、千利休 x ミニマリズム
4. **Vibe Coding タイムアタック** - 視聴者のアプリアイデアを受け付け、Claude Code / Cursor で制限時間内に完成させるライブ配信
5. **AI裁判ショー** - AIに検察と弁護を演じさせ、視聴者が裁判員として判決を下すエンタメ形式

### カテゴリB: 教育・チュートリアル系

6. **Claude Code 完全マスター講座（日本語）** - 英語圏では大量にあるが日本語での体系的チュートリアルがほぼゼロ。インストールから Routines / MCP サーバーまで網羅
7. **ローカルLLM構築チュートリアル（日本語版）** - Ollama + LM Studio + AnythingLLM を日本語で丁寧に解説。プライバシー重視の日本市場に刺さる
8. **AIエージェント構築ハンズオン** - 「自分専用AIエージェントを30分で作る」系の実践動画。日本語でのエージェント構築コンテンツは皆無に近い
9. **業界特化型AI活用シリーズ** - 「不動産営業 x AI」「飲食店経営 x AI」「美容師 x AI」等、特定業種に絞ったAI活用法。日本のnote記事では注目されているがYouTubeではほぼ空白
10. **非エンジニアのためのAIアプリ開発** - Base44 / Lovable / Bolt.new を使った完全ノーコードアプリ開発。日本語チュートリアルが決定的に不足

### カテゴリC: エンタメ・バイラル系

11. **AI怪談チャンネル** - AI映像生成 + AI音声で「本当にあった怖い話」を映画品質で再現。日本の怪談文化は世界最強の素材
12. **AIで作るJ-POP / アニソン** - Suno / Udio でJ-POP・アニソンを作り、制作過程を全公開。「AIが作った曲をプロに聴かせたら？」のリアクション動画と組み合わせ
13. **AI料理モッパン（日本版）** - 韓国で流行のAI食文化動画の日本版。江戸時代の人がラーメンを初めて食べるAI動画など
14. **歴史POV動画（AI日本史版）** - 「POV: あなたは関ヶ原の戦いの足軽です」等、AI映像で日本史の一場面を一人称体験。英語圏で数千万再生のフォーマット
15. **AIペット動画** - ペットがAI音声で「喋る」動画。韓国の「犬がインタビューに答える」フォーマットの日本版

### カテゴリD: ビジネス・自己成長系

16. **30日AIチャレンジ ドキュメンタリー** - 30日間AIだけで副業/起業し、収益を毎日公開する長期シリーズ
17. **AIで月収100万円ロードマップ** - AIツールを使った具体的な収益化方法を体系的に解説。英語圏では「$215M AI CEO Playbook」等がバズっているが日本語版がない
18. **AI転職・キャリア戦略** - 「AIに仕事を奪われる人 vs AIで年収が上がる人」の分析。具体的なスキルロードマップ付き
19. **AIで英語学習 完全攻略** - ChatGPT / Claude を英語教師として使い倒す方法。TOEIC対策 x AI の組み合わせ
20. **Faceless AI自動化チャンネル構築法** - 顔出しなしでAIを使ってYouTubeチャンネルを成長させる方法を日本語で体系的に解説。英語圏では巨大ジャンルだが日本語コンテンツはほぼゼロ
