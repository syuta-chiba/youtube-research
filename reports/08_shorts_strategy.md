## バズっているAI Shortsのパターン10選

### 1. マイクロリスト型（Micro-Listicle）
- **例**: 「AIツール神5選、最後が最強」「ChatGPTでできること3つ」
- **構成**: フック(1秒) → 項目を高速テンポで紹介(25秒) → 最後の1つで驚かせる(4秒)
- **なぜ伸びる**: スキマブルで再視聴率が高い。AI生成しやすく量産向き
- **再生数目安**: 10万〜500万回

### 2. Before/After 変換型（Transformation）
- **例**: 「AIに自分の写真を渡したら…」「古い写真をAIで復元してみた」
- **構成**: ビフォー画像(2秒) → AI処理の演出(3秒) → アフター画像でドン(5秒)
- **なぜ伸びる**: 好奇心と満足感のダブル刺激。視覚的インパクトが強くスワイプされにくい

### 3. POV（一人称視点）型
- **例**: 「POV: 上司にChatGPTの使い方を教える」「POV: AIに仕事を奪われた日」
- **構成**: テキストオーバーレイでシチュエーション提示 → 短いスキット or 画面録画
- **なぜ伸びる**: 感情的な共感を生みやすく、コメント欄が活性化する

### 4. パターンブレイク型（予想裏切り）
- **例**: 「AIに絵を描かせたら…（最後にまさかの結果）」
- **構成**: 予想できる展開で始める → 途中or最後で予想を裏切る
- **なぜ伸びる**: 「最後まで見ないとわからない」構造で完視聴率が爆上がり

### 5. ツールデモ型（Speed Demo）
- **例**: 「この無料AIで30秒でロゴが作れる」「Soraでこんな動画が作れる」
- **構成**: 問題提示(2秒) → ツール操作の早送り(20秒) → 完成物を見せる(8秒)
- **なぜ伸びる**: 実用的で保存率が高い。「使ってみたい」でコメントも増える

### 6. 「これ知ってた？」トリビア型
- **例**: 「ChatGPTの隠しコマンド3選」「99%が知らないAI活用法」
- **構成**: 衝撃的な事実を冒頭で提示 → 補足説明 → 「シェアして」で締め
- **なぜ伸びる**: 知識欲を刺激し、シェア動機が生まれやすい

### 7. AI vs 人間 比較型
- **例**: 「プロの画家 vs Midjourney、どっちがうまい？」「ChatGPT vs 東大生」
- **構成**: お題提示(3秒) → 双方の結果を並べて見せる(20秒) → 視聴者に投げかけ(5秒)
- **なぜ伸びる**: 議論を呼びコメント数が爆増。アルゴリズムが高評価

### 8. AIミーム/コメディ型
- **例**: 「ChatGPTに告白させてみた」「AIが考えた最悪のビジネス」
- **構成**: 突飛な設定(2秒) → AIの回答をテンポよく表示 → オチ(3秒)
- **なぜ伸びる**: エンタメ系は全ジャンルの70%を占め、最もシェアされやすいカテゴリ

### 9. マイクロドラマ型（2026年トレンド）
- **例**: 「AIが人類を超えた日（60秒SF）」
- **構成**: AI生成映像+ナレーションで60秒の自己完結ストーリーを展開
- **なぜ伸びる**: 2026年のShortsトレンドとして「マイクロドラマ」が急伸中

### 10. ループ構造型
- **例**: 最後のセリフが最初につながり、無限ループで再生回数が倍増
- **構成**: 結末の最後のワード → 冒頭のフックにシームレスに接続
- **なぜ伸びる**: 再生回数が物理的に2〜3倍になる。アルゴリズムが「高リテンション」と判定

## Shorts用の鉄板フォーマット

### フォーマット一覧

| フォーマット | フック例 | 尺の目安 | 難易度 |
|---|---|---|---|
| A vs B（AI比較） | 「ChatGPT vs Gemini、勝ったのは…」 | 30秒 | 低 |
| 「これ知ってた？」系 | 「99%が知らないAIの裏ワザ」 | 15-20秒 | 低 |
| Before/After系 | 「この写真、AIで復元したら…」 | 15秒 | 低 |
| ツールデモ系 | 「無料AIで○○が30秒で完成」 | 30-45秒 | 中 |
| ランキング系 | 「AI画像生成ツールTOP5」 | 30秒 | 低 |
| チャレンジ系 | 「AIだけで1時間でアプリ作れる？」 | 45-60秒 | 高 |
| POVコメディ系 | 「POV: AIに仕事を任せた結果」 | 15-20秒 | 中 |
| 速報ニュース系 | 「GPT-5がヤバい。3つのポイント」 | 20秒 | 低 |
| 反論・逆張り系 | 「AIで稼げるは嘘。本当の理由」 | 30秒 | 中 |
| 実験検証系 | 「AIに100回同じ質問したら…」 | 30-45秒 | 中 |

### 黄金構成テンプレート（30秒版）

```
[0-3秒] フック: 衝撃的な事実 or 結論先出し（テキスト大文字オーバーレイ）
[3-5秒] 問題提起: 「でも実は…」「なぜかというと…」
[5-20秒] 本編: 1.5秒ごとに画面変化、テンポよく情報を展開
[20-25秒] クライマックス: 最も衝撃的な情報 or 結果
[25-28秒] CTA: 「フォローで毎日AI情報」「続きは概要欄」
[28-30秒] ループポイント: 冒頭に自然につながるカット
```

### フック（冒頭3秒）の鉄板パターン

1. **逆張り型**: 「みんな○○って言うけど、それ間違い」
2. **数字インパクト型**: 「たった30秒で○○ができる」
3. **チェックリスト型**: 「これ全部無料。知らなきゃ損」
4. **結果先出し型**: 完成品や衝撃結果を先に見せる
5. **証拠提示型**: 「実際にやってみた結果がこれ」
6. **緊急性型**: 「今すぐ使わないと損するAIツール」

### アルゴリズム攻略の数値目標（2026年版）

- **完視聴率**: 70%以上を目指す（バイラル動画の平均は76%）
- **スワイプ率**: 最初の3秒で50-60%が離脱するため、フックが最重要
- **最適尺**: 15〜30秒（エンゲージメント最大化）
- **シード配信**: 最初の200〜800回再生でリテンション70%超えれば次のティアに拡散
- **投稿頻度**: 最低週3本、理想は毎日1本

## Shortsから長尺への導線設計

### 基本戦略: Shortsは「発見」、長尺は「定着」

YouTube公式データ（2026年）によると、Shorts+長尺動画の両方を投稿するクリエイターは:
- 登録者の成長速度が **3倍**
- 総再生時間が **2.5倍**
- Shortsから長尺に遷移した視聴者のLTV（生涯価値）は **40%高い**

### 具体的な導線設計パターン

#### パターン1: ティーザー型
```
Shorts: 「ChatGPTの裏ワザ3選」（30秒）
  ↓ 固定コメント「全10選はこちら→」
長尺: 「ChatGPT完全攻略ガイド 裏ワザ10選」（15分）
```

#### パターン2: 続きが気になる型
```
Shorts: 「AIで副業して1ヶ月目の結果…」（途中で終わる）
  ↓ 概要欄「全記録はこちら」
長尺: 「AIで副業チャレンジ 30日間の全記録」（20分）
```

#### パターン3: フラッド・メソッド（Flood Method）
```
1本の長尺動画から5〜15本のShortsを作成
全Shortsの「関連動画」に同じ長尺動画をリンク
→ 複数のShortsから1つの長尺に集中的にトラフィックを流す
```

#### パターン4: シリーズ化型
```
Shorts: 「AIツール紹介 Day 1」〜「Day 30」（毎日投稿）
  ↓ まとめ動画
長尺: 「30日間で試したAIツール全レビュー」（30分）
```

### 実装チェックリスト
- [ ] YouTube Studioで各Shortsに「関連動画」を設定する
- [ ] Shortsの固定コメントに長尺動画のリンクを貼る
- [ ] Shorts概要欄に長尺動画のURLを記載する
- [ ] Shortsの最後に「詳しくはチャンネルの○○動画で」と音声で誘導
- [ ] チャンネルページの再生リストで「Shorts→長尺」の流れを設計
- [ ] 週のスケジュール: Shorts 5本 + 長尺 1本の投稿ペースを維持

### 収益化の条件と目安（2026年版）

#### YPPの参加条件（段階的）
| レベル | 登録者 | 再生条件 | 解放される収益 |
|---|---|---|---|
| ファンファンディング | 500人 | 90日で300万Shorts視聴 | スーパーサンクス・メンバーシップ |
| 広告収益 | 1,000人 | 90日で1,000万Shorts視聴 | Shortsフィード広告 |

#### 収益の目安
- Shorts CPM: 600〜1,800円
- 1,000万再生で約5万〜15万円（広告収益のみ）
- ただしスポンサード・アフィリエイト・自社商品誘導の方が収益性は高い

#### AI生成コンテンツの注意点
- 2025年7月ポリシー改定: 「AIによる大量生産・反復的コンテンツ」は収益化除外対象
- 対策: テンプレを使い回しつつも、毎回異なる切り口・独自の解説を加える
- AI生成であることのラベル付けが必須（YouTube Studio内で設定）
- YouTube自体がAI機能（Veo、AIアバター等）を提供しているため、「AIツールの活用」自体は問題ない。問題は「独自性のない大量コピー」
