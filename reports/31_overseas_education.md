## 英語圏で人気だが日本語にまだないテーマ

### 1. AI Second Brain 構築の完全ワークフロー
英語圏では Tiago Forte が「The AI Second Brain」コースを発表し、Taskade / Recall / NotebookLM を組み合わせた「AI第二の脳」構築が大ブーム。日本語では「第二の脳」は Obsidian 単体の紹介に留まり、AI エージェントを絡めた統合ワークフローの解説動画はほぼ皆無。

### 2. YouTube動画 → AIフラッシュカード → 間隔反復学習パイプライン
StudyGlen / Atlas AI / RemNote などが「YouTube URL を貼るだけで FSRS アルゴリズムによる間隔反復フラッシュカードが自動生成」という機能を提供。2026年のメタ分析（21,415人対象）で間隔反復の大きな効果が実証されたが、日本語でこの一連のパイプラインを解説した動画はない。

### 3. NotebookLM Cinematic Video Overviews（動画解説の映像版）
2026年3月に Gemini 3 + Veo 3 で「Cinematic Video Overviews」がローンチ。英語圏では多数のチュートリアルが出ているが、日本語での実践レビューはほぼゼロ。

### 4. Recall 2.0 — 個人ナレッジベースの新標準
50万人以上が利用する Recall が 2026年4月に 2.0 をリリース。GPT / Claude / Gemini / Grok / DeepSeek を切り替えながら自分の保存データに基づいた回答を得られる。日本語レビュー動画は見当たらない。

### 5. AI Podcast 化学習法（NotebookLM / BibiGPT / BeFreed）
教材を AI ポッドキャストに変換して通勤中に学ぶワークフロー。BibiGPT は2ホスト会話形式を生成。日本語では NotebookLM の音声概要のみ紹介されており、BibiGPT や BeFreed は未紹介。

### 6. YouTube → マインドマップ自動変換（Mapify / NinjaChat）
YouTube URL からワンクリックでマインドマップを生成するツール群。英語圏では Mapify が Chrome 拡張で大人気だが、日本語でのチュートリアル動画はほぼない。

### 7. AI × 語学学習の YouTube 活用（Trancy / Sabi / FluentU）
Trancy は AI バイリンガル字幕 + GPT 文法解析 + AI スピーキングコーチを提供。Sabi は YouTube 視聴中にホバー翻訳。日本語圏では Language Reactor の紹介のみで、これらの新ツールは未カバー。

### 8. MensorAI — YouTube 学習特化型ノートアプリ
Chrome 拡張で YouTube 上に直接ノートを取り、AI Q&A と間隔反復プロンプトを統合。日本語紹介なし。

### 9. Obsidian + Claude Code で自己更新するナレッジベース
Karpathy の LLM Wiki 手法を使い、Claude Code で 6 プロジェクトの知識ベースを自動メンテナンスする事例が HackerNoon で話題。日本語では Obsidian + AI の基本紹介のみ。

### 10. AI 試験対策の統合ワークフロー（YouLearn / Mindgrasp）
YouTube 動画 → 文字起こし → ノート → フラッシュカード → 模擬試験 → AI チューター という一気通貫のワークフロー。英語圏では YouLearn や Mindgrasp がこれを実現しているが、日本語での包括的解説はない。

### 5. Trancy で YouTube 語学学習を革命する
AI バイリンガル字幕 + 文法解析 + スピーキングコーチ。英語学習系 YouTuber が触れていない新ツール。

### 6. BibiGPT で講義を AI ポッドキャストに変換

### 7. Mapify で YouTube → マインドマップ一発変換

### 8. Obsidian + Claude Code 自動ナレッジベース
