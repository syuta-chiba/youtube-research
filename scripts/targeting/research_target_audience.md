# 日本n8n動画 ターゲット層分析

## 調査概要
- 調査日: 2026年4月20日
- 調査手法: Web検索による公開データ・調査レポートの横断分析（20回以上のWebSearch実施）
- 対象: 日本国内でn8n/AI自動化コンテンツに興味を持つ潜在視聴者層

## 2. 潜在視聴者の5つのペルソナ

### ペルソナA:「効率化マニアの若手エンジニア」
- **年齢**: 25-32歳 / **職種**: Webエンジニア・SIer / **年収**: 400-600万円
- **何に困っているか**: 手作業のデプロイ・通知・データ連携が面倒。Zapierは高い。社内ツール連携を自力で組みたい
- **何を求めているか**: n8nのセルフホスト方法、API連携の具体例、Docker環境構築、実践的なワークフロー
- **反応するタイトル**: 「n8nをDockerで無料構築 → Slack×GitHub×Notion自動連携が神すぎた」
- **好みの動画の長さ**: 15-25分（チュートリアル形式、コード画面多め）
- **視聴タイミング**: 平日夜・週末

### ペルソナB:「DXに焦る中小企業の経営者・管理職」
- **年齢**: 38-52歳 / **職種**: 中小企業経営者・部長クラス / **年収**: 600-1,200万円
- **何に困っているか**: 「AIやらなきゃ」と思うが何から始めればいいかわからない。IT人材がいない。コストが読めない。RPAは高くて断念した
- **何を求めているか**: 「うちの会社でもできる」具体例。投資対効果。導入の全体像。専門用語なしの説明
- **反応するタイトル**: 「IT担当ゼロの会社がn8nで月40時間の事務作業を自動化した方法」
- **好みの動画の長さ**: 8-15分（概要・メリット中心、画面操作は最小限）
- **視聴タイミング**: 通勤中（音声メイン）、昼休み

### ペルソナC:「AIで副業・独立を目指す会社員」
- **年齢**: 27-38歳 / **職種**: 営業・事務・マーケ職（非エンジニア） / **年収**: 350-550万円
- **何に困っているか**: プログラミングができない。でもAIを使って稼ぎたい。何から始めればいいか分からない。情報が多すぎて選べない
- **何を求めているか**: 「プログラミング不要」「無料で始められる」「真似するだけ」の具体的手順。副業としてのマネタイズ方法
- **反応するタイトル**: 「コード書けなくてOK。n8nで"AI自動化の代行屋"として月10万稼ぐロードマップ」
- **好みの動画の長さ**: 12-20分（ステップバイステップ、画面共有メイン）
- **視聴タイミング**: 平日夜21時以降、週末

### ペルソナD:「業務効率化を任されたバックオフィス担当」
- **年齢**: 28-45歳 / **職種**: 経理・総務・人事・情シス / **年収**: 350-550万円
- **何に困っているか**: Excelやスプレッドシートの手作業が多い。上司から「DXしろ」と言われるが予算がない。GASやVBAは挫折した
- **何を求めているか**: Google Sheets連携、メール自動送信、承認フロー自動化など「今の業務をそのまま自動化」できる具体例
- **反応するタイトル**: 「毎月3日かかる請求書処理をn8nで30分に短縮した全手順」
- **好みの動画の長さ**: 15-25分（実際の画面操作を丁寧に見せる）
- **視聴タイミング**: 業務時間中（上司に見せるため）、平日夜

### ペルソナE:「最新ツールを追うマーケター・SNS運用者」
- **年齢**: 25-40歳 / **職種**: Webマーケター・SNS運用・広告運用 / **年収**: 400-700万円
- **何に困っているか**: SNS投稿、レポート作成、リード管理が手作業。ツール間のデータ連携が煩雑。広告費は増えるが人は増えない
- **何を求めているか**: SNS自動投稿、GA4データ自動レポート、CRM連携、AIによるコンテンツ生成パイプライン
- **反応するタイトル**: 「n8n × ChatGPT × SNS で"コンテンツ自動生産ライン"を構築してみた」
- **好みの動画の長さ**: 10-18分（ビフォーアフター重視、成果数字あり）
- **視聴タイミング**: 平日日中（業務の参考として）

## 3. 最もリーチしやすい層はどれか

### 第1位: ペルソナC「AIで副業・独立を目指す会社員」
**理由:**
- YouTube上で「AI 副業」「AI 稼ぐ」系のコンテンツは爆発的に伸びている
- 社会人の約4人に1人が副業経験、Z世代の40%が副業を持つ時代
- 「プログラミング不要」「無料」というフックが最もクリック率が高い
- 競合チャンネルが多いが、n8nに特化した日本語コンテンツはまだ少ない
- SNSでの拡散力が高い（「こんなの見つけた」系シェア）

### 第2位: ペルソナA「効率化マニアの若手エンジニア」
**理由:**
- n8nへの技術的興味が最も強い層
- Qiita、Zenn、noteなどの技術ブログとの相乗効果
- コメント・議論が活発 → エンゲージメント率が高い
- ただしパイ（母数）はペルソナCより小さい

### 第3位: ペルソナE「マーケター・SNS運用者」
**理由:**
- 業務直結の「使える」コンテンツへの反応が早い
- 自身がSNS運用しているため拡散してくれやすい

## 4. 最もマネタイズしやすい層はどれか

### 第1位: ペルソナB「DXに焦る中小企業の経営者・管理職」
**理由:**
- 決裁権を持っている → コンサル・導入支援・有料講座への課金ハードルが低い
- 「時間をお金で買う」マインドセットがある
- n8n導入支援サービス（月額5-30万円）のリード獲得に直結
- 1件の法人契約 = 個人課金100件分以上の価値
- 想定マネタイズ:
  - n8n導入コンサルティング（月額10-30万円）
  - 法人向けオンライン講座（10-30万円/社）
  - 個別カスタマイズ開発（50-200万円/案件）

### 第2位: ペルソナC「AIで副業・独立を目指す会社員」
**理由:**
- 「稼ぎたい」モチベーションが強く、教材・講座への投資意欲が高い
- オンラインコース（3-10万円）、メンバーシップ（月額980-2,980円）の購買層
- 数の力: 単価は低いがボリュームが大きい
- 想定マネタイズ:
  - Udemy/自社オンラインコース（5,000-30,000円）
  - YouTubeメンバーシップ（月額490-2,990円）
  - テンプレート販売（n8nワークフロー集: 3,000-10,000円）

### 第3位: ペルソナD「バックオフィス担当」
**理由:**
- 法人経費で購入される可能性がある
- 「上司を説得する資料」としての動画 → 法人チャネルへの導線

## 5. emperor_chが狙うべきメインターゲット提案

### 推奨戦略:「ペルソナC（副業層）で集客し、ペルソナB（経営者層）でマネタイズ」

#### フェーズ1: チャンネル成長期（0-6ヶ月）
**メインターゲット: ペルソナC + ペルソナA**

狙い: チャンネル登録者・再生数の最大化

- 「n8n × AI で○○を自動化してみた」系の実演動画
- 「プログラミング不要」を前面に出す
- 副業・収益化の文脈を織り交ぜる
- エンジニア層のコメント・シェアでSEO強化

#### フェーズ2: 権威構築期（6-12ヶ月）
**メインターゲット: ペルソナD + ペルソナE**

狙い: 「n8n = emperor_ch」のブランディング

- 業種別・業務別の具体的自動化事例
- 「○○業界の○○をn8nで自動化」シリーズ
- 企業事例・導入ビフォーアフター

#### フェーズ3: マネタイズ期（12ヶ月以降）
**メインターゲット: ペルソナB**

狙い: 法人向けサービスの展開

- 経営者向け「n8nで始めるAI自動化経営」シリーズ
- 無料セミナー → コンサル・導入支援への導線
- 法人向け研修プログラム

### なぜこの順番か
1. **ペルソナCは「入口」として最強**: YouTubeアルゴリズム上、再生数とエンゲージメントが命。副業層は最もクリック・視聴・シェアしてくれる
2. **ペルソナBは「出口」として最強**: 1社の法人案件 = YouTube広告収入数年分。だが経営者はYouTubeで「検索」しない → まず認知を広げてからリーチする必要がある
3. **ペルソナAはSEOの味方**: エンジニアがQiita/Zenn/Xでシェア → 検索流入が増える → 他ペルソナも流入

## 6. ターゲット別のタイトル・構成の変え方

### ペルソナA向け（エンジニア層）
**タイトルパターン:**
- 「n8n × Docker × Claude API で全自動○○システムを構築する」

- 「n8nのFunction Nodeでやれること全部見せる【上級者向け】」

**構成:**
1. 完成形デモ（30秒）
2. アーキテクチャ概要（2分）
3. ハンズオン構築（15-20分）
4. つまずきポイントと解決策（3分）
5. 応用アイデア（2分）

**トーン:** 技術的・フラット・コード画面多め
**サムネイル:** ダーク背景 + コード + 技術ロゴ

---

### ペルソナB向け（経営者・管理職層）
**タイトルパターン:**
- 「社員5人の会社がn8nで年間480時間の事務作業を消した方法」

**構成:**
1. 課題の共感（痛みの提示）（1-2分）
2. 解決策の全体像（n8nとは何か、30秒で）（2分）
3. 具体的な導入事例（ビフォーアフター数字）（3-5分）
4. コストと導入ステップ（2分）
5. 「まず何をすべきか」明確なCTA（1分）

**トーン:** ビジネス・信頼感・数字で語る
**サムネイル:** スーツ姿 + 大きな数字（「月40時間削減」等）

## 7. 補足データ・市場環境

### n8nの日本市場ポジション
- 世界で13,180社以上が利用、評価額$25億（2025年Series C: $180M調達）
- 日本ではまだ黎明期 → 「日本語n8n情報の第一人者」ポジションが取れる最後のチャンス
- Zapier（初心者向け・高額） vs Make（中級者向け） vs n8n（技術者・コスト重視） の3極構造
- n8nのセルフホスト（無料）という特徴は、日本の中小企業・個人に最も刺さるUSP

### YouTube市場環境
- 日本のYouTube月間視聴者: 7,120万人
- 最もリーチできる年齢層: 25-34歳（男女とも）
- テック系チュートリアルの需要は増加傾向だが、n8n特化の日本語チャンネルはほぼ不在
- AI系YouTubeチャンネルは2024-2025年に急増したが、「自動化ツール実演」に特化したチャンネルは少ない

### 日本のRPA/自動化市場
- 2025年: 9.112億ドル → 2034年: 57.8億ドル予測（年平均成長率22.79%）
- 大企業のRPA導入率27.69%、中小企業8.51% → 中小企業向けの低コスト自動化に巨大な需要
- AI × RPA の組み合わせに53%の企業が関心

### 日本の生成AI利用の現状
- 個人利用率: 26.7%（前年9.1%から急増）
- 企業利用率: 55.2%（ただし多くは試験導入段階）
- 「使い方がわからない」が最大の未利用理由 → チュートリアル動画の需要を裏付け

## 8. 結論: emperor_chの最適ポジショニング

**「日本で唯一のn8n専門チャンネル」として、"非エンジニアでもできるAI自動化"を旗印に、副業層で集客 → 法人層でマネタイズする二段構えの戦略が最も合理的。**

市場タイミングとしては、日本のn8n認知がまさに立ち上がるフェーズであり、今から参入すれば「日本語n8n = emperor_ch」のポジションを確立できる。この先1-2年で競合が増える前に、圧倒的な動画本数とSEO占有率を構築することが最優先課題。
