## サムネイルとの組み合わせ提案

### 原則: タイトルとサムネイルは「補完関係」であるべき

タイトルとサムネイルが同じ情報を繰り返すのはNG。タイトルで「what（何）」を伝え、サムネイルで「wow（驚き/感情）」を伝えるのが鉄則。

## 公開後のタイトル変更戦略

### Phase 1: 公開直後（0-48時間）-- データ収集期

| 指標 | 確認ポイント |
|------|------------|
| インプレッション数 | 最低1,000インプレッション以上ないとCTR判断不可 |
| CTR | 目標: 8%以上。5%未満なら即座にPhase 2へ |
| 平均視聴時間 | 50%以上ならコンテンツは問題なし。タイトル/サムネで改善可能 |
| 流入経路 | 「YouTube検索」の割合を確認。検索流入が多い＝タイトルSEOが機能 |

### Phase 2: 初回タイトル変更（48-72時間後）

**CTRが5%未満の場合、以下の順序で変更を試す:**

1. **パワーワードの追加/変更**: 括弧内のワードを変える（例:「保存版」→「永久保存」）
2. **フレーミングの変更**: 利益訴求→損失回避に切り替え（例:「始め方」→「知らないと損」）
3. **数字の追加**: 具体的数字がない場合は追加（例:「自動化する方法」→「3つの業務を自動化」）

**注意: 一度に変更するのは1要素のみ。複数同時変更は効果測定ができなくなる**

### Phase 3: YouTube公式A/Bテスト（1週間後〜）

YouTubeの「テストと比較」機能を使い、以下の組み合わせをテスト:

| テストID | バリアントA（現タイトル） | バリアントB（テスト用） |
|---------|------------------------|----------------------|
| Test-1 | 【保存版】n8nでAI自動化！日本語で一番やさしい完全ガイド | 【知らないと損】n8nで業務を全自動化する方法｜無料 |
| Test-2 | 勝者 | Zapierに月1万払ってた自分を殴りたい｜n8nが無料で最強 |
| Test-3 | 勝者 | 無料でここまでできる？n8nのAI自動化が凄すぎた |

- テスト期間: 各バリアント最低1週間（推奨2週間）
- 評価指標: Watch Time Share（YouTube公式はCTRではなく視聴時間で判定）
- 最低インプレッション: バリアントあたり1,000以上

### Phase 4: 長期最適化（1ヶ月後〜）

| タイミング | アクション |
|-----------|----------|
| 1ヶ月後 | 検索キーワードレポートを確認。想定外のキーワードで流入があれば、タイトルにそのキーワードを組み込む |
| 3ヶ月後 | エバーグリーン化。年号が入っている場合は削除を検討 |
| 6ヶ月後 | 再度A/Bテスト実施。視聴者層の変化に合わせたタイトル調整 |
| 次の動画公開時 | 前回の当たりタイトルのフォーマットを踏襲（例:「【保存版】」が勝者なら次も使う） |

### Phase 5: シリーズ展開時のタイトル統一戦略

1本目が成功したら、以下のシリーズタイトルフォーマットを確立:

```
【保存版】n8n × ○○連携で△△を自動化する方法
```

例:
- 【保存版】n8n × kintone連携で顧客管理を自動化する方法
- 【保存版】n8n × freee連携で経費精算を自動化する方法
- 【保存版】n8n × LINE Bot連携で問い合わせ対応を自動化する方法

**統一フォーマットの効果:**
- チャンネルのブランド認知が向上（「あのn8n連携の人」）
- シリーズ感が出て関連動画に表示されやすくなる
- 視聴者が「次はどのサービスと連携するのか」と期待する構造
