# n8n動画 シリーズ展開・長期戦略

## シリーズ化のメリット（データ根拠）

### 視聴維持率の向上
- シリーズ動画はエンドスクリーンCTAのクリック率が **8-10%** に達する（通常の動画は3-7%）
- プレイリスト最適化により、チャンネル成長率が **20-30%向上** するデータあり
- セッション時間（1回の訪問で複数動画を視聴する時間）がアルゴリズム評価で重要視されており、シリーズはこれを自然に伸ばす

### 視聴者の習慣化
- エピソード型シリーズは「来週も見よう」という習慣を形成し、リピート視聴を促進
- エバーグリーン型シリーズは検索経由で長期的に新規視聴者を獲得し続ける
- 両方を組み合わせることで、短期的な勢いと長期的な安定成長を両立できる

### チャンネル権威性の構築
- Nate Herkは2年未満で65万人超の登録者を獲得。体系的なシリーズ（マスタークラス、AIエージェント構築）が核
- Nick Saraevは307,845人（2026年3月時点）→ 2026年末100万人を目標。シリーズ化と検索SEO最適化が戦略の柱
- コンテンツピラー（3-5テーマ）を設定し、シリーズをローテーションすることで、ニッチの専門性を維持しつつ多様性を確保

### YouTubeアルゴリズムへの効果
- 2026年は再生回数より **リテンション（視聴維持率）** が重視される
- 公式シリーズ（YouTube機能）に設定すると、シリーズ内の他の動画がおすすめに表示されやすくなる
- プレイリストは検索結果にも表示され、個別動画以外のSEO流入チャネルになる

## シリーズ間の導線設計

### 1. 垂直導線（初級→上級への階段）
```
パターンA（入門）→ パターンB（実践） → パターンC（上級）
         ↓                ↓                    ↓
      基礎理解          業務適用           ビジネス化
```

**具体的な誘導方法**:
- パターンA最終話で「基礎が身についたら、実践レシピ集へ」とCTA
- パターンB各動画の冒頭で「基礎がまだの方はマスタークラスから」と案内
- パターンCの動画説明欄に「前提知識：マスタークラスの〇〇回まで視聴推奨」

### 2. 水平導線（シリーズ間の相互リンク）
- パターンBの「AIカスタマーサポートBot」→ パターンCの「RAGチャットボット」へ誘導
- パターンCの「AIエージェント商品化」→ パターンAの「マネタイズ編」へ誘導
- 各動画の説明欄に「関連動画」セクションを設け、他シリーズの関連動画をリンク

### 3. エンドスクリーン戦略
- **ルール**: 必ず口頭CTAとエンドスクリーンを同期させる
- **テンプレート**: 「次のステップとして〇〇の動画を見てください。〇〇の方法がわかります」
- **シリーズ内の次動画**: 左側に配置（メインCTA）
- **他シリーズへの誘導**: 右側に配置（サブCTA）

### 4. Shorts → 本編への導線
- 各シリーズの動画から30-60秒のShorts（ハイライト/Tip）を切り出し
- Shorts説明欄・コメントピン留めで本編フル動画へ誘導
- Shortsは新規視聴者の発見エンジンとして活用

### 5. プレイリスト設計
- **公式シリーズ機能を使用**: YouTubeの「公式シリーズ」に設定し、おすすめ表示を強化
- **プレイリスト名にキーワードを含める**:
  - 「n8n入門マスタークラス - ゼロから学ぶ自動化」
  - 「n8n実践レシピ集 - 業務自動化ワークフロー」
  - 「n8n AIエージェント構築 - 上級者向け」
- **プレイリスト説明文**にもキーワードを盛り込み、検索からの流入を狙う
- **プレイリストあたり4-10動画**が最適（完走率が高い）

## 投稿スケジュール

### 推奨頻度: 週2本（長尺1本 + Shorts 1-2本）

実験データによると、週7本（毎日）にしても視聴回数は約25%増にしかならず、作業量は7倍。週1-3本が最もコスパが良い。

### 6ヶ月ロードマップ

| 月 | メインシリーズ | サブコンテンツ | 目標 |
|---|-------------|-------------|-----|
| **Month 1-2** | パターンA（入門）#1-8 | Shorts × 8本 | 基盤構築・初期視聴者獲得 |
| **Month 3** | パターンA #9-10 + パターンB #1-4 | Shorts × 6本 | 入門完結 → 実践へ移行 |
| **Month 4** | パターンB #5-8 | Shorts × 4本 + 比較動画1本 | 実践レシピ充実 |
| **Month 5** | パターンB #9-12 + パターンC #1-2 | Shorts × 4本 | 上級シリーズ開始 |
| **Month 6** | パターンC #3-6 | Shorts × 4本 | AIエージェント上級 |

### 週間スケジュール例
| 曜日 | コンテンツ | 備考 |
|-----|----------|-----|
| 月 | 撮影・編集 | メイン動画の制作 |
| 火 | メイン動画公開 | 長尺（10-20分） |
| 水 | Shorts編集・公開 | メイン動画からの切り出し |
| 木 | 次回リサーチ・台本 | |
| 金 | 予備 or 追加Shorts | コミュニティ投稿も |
| 土日 | バッチ撮影 or 休息 | 2-3本まとめ撮りも有効 |

### コンテンツピラーのローテーション
3つのシリーズを**同時並行せず、フェーズで切り替える**のが鍵。理由:
1. 初心者が入門シリーズを追いかけやすい
2. 制作負荷が分散される
3. 各フェーズで異なるターゲット層にリーチし、チャンネルの幅を広げる

## シリーズ→有料コースへの転換戦略

### ファネル全体像
```
YouTube無料シリーズ（認知・信頼構築）
        ↓
  メールリスト登録（リードマグネット）
        ↓
  メールナーチャリング（7日間シーケンス）
        ↓
  有料コース購入（中〜高単価）
        ↓
  コミュニティ/コンサル（高単価リピート）
```

### 無料 vs 有料の線引き
| 無料（YouTube） | 有料（コース） |
|---------------|-------------|
| What（何をするか）・Why（なぜ必要か） | How（詳細な実装手順） |
| 1つの課題を1動画で解決 | 体系的カリキュラム |
| 基本的なワークフロー | 高度なカスタマイズ・テンプレート |
| 概要レベルのデモ | コピー可能なテンプレート付き |
| コミュニティサポートなし | 質問対応・メンタリング付き |

### 具体的な有料コース構成案

**コース1: n8n AIエージェント構築マスターコース（29,800円）**
- パターンCの内容を深掘り + テンプレート50個付き
- 全10モジュール、30時間以上のコンテンツ
- プライベートコミュニティアクセス

**コース2: n8n自動化ビジネス立ち上げコース（49,800円）**
- クライアント獲得〜納品までの実務フロー
- 提案書・契約書テンプレート付き
- 月1回のグループコーチング

### コンバージョン率の目安
- YouTube視聴者 → メールリスト登録: **1-3%**
- メールリスト → セールスページ訪問: **5-15%**
- セールスページ → 購入: **1.5-5%**（ウォーム層）
- 9日間チャレンジファネル経由: **10-20%**（2026年最高効率の手法）

### 収益モデルのスケーリング（Nate Herkモデル参考）
| 収益源 | 月間目標 | 備考 |
|-------|---------|-----|
| YouTube広告収入 | 5-30万円 | 登録者数・再生回数に依存 |
| 有料コース販売 | 30-100万円 | エバーグリーン販売 |

| テンプレート販売 | 5-20万円 | パッシブ収入 |

Nate Herkの実績: YouTube広告だけで月$6,000+、AI自動化事業で月$100,000+を達成。YouTubeは「入口」であり、本丸は教育事業とコンサルティング。
