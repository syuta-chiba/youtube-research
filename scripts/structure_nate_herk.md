## Nate Herkの構成パターンまとめ

### 1. 冒頭パターン: 「デモファースト」
- ほぼ全ての動画が**最初の0-2分でデモ・完成品を見せる**
- 「こんなものが作れる」を先に見せてから作り方を教える
- 視聴者が「これを自分も欲しい」と感じてから解説に入る

### 2. 無料テンプレートCTA: 動画の15-30%地点
- デモ直後（全体の約20%前後の地点）で「Download This Template Free」を挿入
- これが視聴継続の強力な動機になる
- テンプレートはSkoolコミュニティ or 概要欄リンクで配布

### 3. 「Build → Test」の反復サイクル
- 特にエージェント系動画では「構築→テスト→次の構築→テスト」を繰り返す
- 視聴者に小さな達成感を連続で提供
- 例: Email Agent Build → Test → Calendar Agent Build → Test

### 4. 明確なPart分割（長尺動画）
- 90分以上の動画は「Part 1, Part 2...」で明確に区切る
- 8時間コースではテーマ別セクション（基礎→実践→API→高度→MCP）
- 初心者が「自分は今どこにいるか」を常に把握できる

### 5. タイトルの型
- **「I Built...」パターン**: 自分が作ったものを紹介（ストーリー性）
- **「How I...」パターン**: 自分のプロセスを共有（親近感）
- **数字入りリスト**: 「17 Essential Nodes」「8+ Hour Course」（具体性）
- **括弧で無料テンプレート明記**: (Free Template), (No Code)（障壁除去）

### 6. 動画の尺の分布
- 短尺（15-25分）: 1つの自動化ワークフローを紹介
- 中尺（30-65分）: ステップバイステップのハンズオン
- 長尺（90分+）: マスタークラス・包括的チュートリアル
- 超長尺（8時間+）: 完全コース

### 7. 収益・ビジネス要素の組み込み
- 「Makes Me $6k/mo」「Sold for $23K」など**具体的な金額**をタイトルに入れる
- 動画内で必ずビジネスの文脈（いくら稼げるか、クライアントにどう売るか）を説明
- 最後のセクションで「Pricing」「Lessons from Building」などビジネス面をカバー

### 8. プラットフォーム連携
- YouTube動画 → Skoolコミュニティ（AI Automation Society）への誘導
- 無料テンプレート → Skool登録のフック
- コミュニティ内で質問対応・追加リソース提供

### 9. ターゲット視聴者
- 完全な初心者（コーディング経験不要を強調）
- フリーランスやエージェンシー志望者（Build & Sell の文脈）
- 既存のn8nユーザー（高度なエージェント構築）

### 10. 差別化要因
- **実体験ベース**: 自分が実際に使っているシステムを公開
- **無料テンプレート**: 視聴者がすぐに始められる
- **ノーコード**: 技術的障壁を徹底排除
- **ビジネス視点**: 技術だけでなく「どう稼ぐか」まで教える
