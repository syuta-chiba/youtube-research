## なぜこの企画なのか（全リサーチからの根拠）

### 企画: 「n8nでGmail受信 → AIが自動要約 → LINE通知する仕組みを15分で作る」

10本のリサーチから導き出した結論として、emperor_chの最初のn8n動画は**「AI連携 x 日本固有サービス（LINE） x 実践ハンズオン」**の交差点を狙う。

**根拠1: 視聴者ニーズ調査より**
- 視聴者が最も求めているのは「完成形を先に見せてから手順を解説」「画面を見せながら一緒に手を動かしたい」「実用的なユースケースが見たい」の3点
- AI連携（ChatGPT/Claude）への関心が最も高い。「n8n + ChatGPT」の組み合わせへの関心が日本で最大
- 日本語でのn8n解説動画は「ブルーオーシャン」状態

**根拠2: キーワード競合度調査より**
- 「n8n LINE」日本語動画は3本程度しかなく、高度なユースケースは皆無
- 「n8n Gmail AI返信」専用動画は少数。ブログからの動画化余地あり
- 日本固有サービス（LINE）との組み合わせは英語圏YouTuberが絶対に作らないコンテンツ

**根拠3: 検索結果監査より**
- 「n8n 使い方」「n8n 入門」は飽和（大手が「完全入門」「保存版」で独占）
- 正面から戦わず、**具体的ユースケース**に絞った動画で差別化する必要がある
- 「n8n kintone」「n8n freee」は動画ゼロだが、実装のハードルが高い。最初の動画としては**誰でも再現できるGmail + LINE**が最適

**根拠4: 差別化ポイント調査より**
- emperor_chのポジション: 「日本語n8n界のNate Herk x 実務特化」
- いけともchが広く浅くカバーする中、n8n一本に絞った深い専門性で差別化
- 10-15分のコンパクトな実践動画を主力にする（いけともchの30-60分長尺との差別化）

**根拠5: ゼロからの初動獲得戦略より**
- 新チャンネルは「検索ファースト」+「外部流入」+「Shorts」の三本柱
- ロングテール「n8n LINE 通知 自動化」「n8n Gmail 自動化」は競合ほぼゼロ
- 最初の動画は「即座に価値が伝わる実用的なワークフロー」であるべき

**なぜ入門動画ではなく実践動画なのか:**
- 「n8n完全入門」は既に大手が押さえている（42万回再生級の動画が存在）
- 登録者1,400人のチャンネルが入門動画で大手に勝つのは非現実的
- 具体的なユースケース動画は検索流入が狙えて、競合が少ない
- 実際に「使える」ワークフローを提供することで、テンプレート配布→ファン化の導線が作れる

### サムネのポイント（心理テクニック適用）
- テキストは3語以内（「全部タダ。」）→ 認知負荷を最小化
- サムネテキスト「全部タダ。」はタイトルの「無料」と異なる表現で補完（重複回避）
- 高コントラスト配色（ダーク背景 x 黄色）→ CTR +20-40%
- ビフォーアフター構図の変形（メール → AI → LINE のフロー）→ 変化を可視化
- 右下にテキストを配置しない（YouTube再生時間オーバーレイ回避）

### A/Bテスト用サブ案
- 案B: 自分の驚き顔を左側に配置 + 右側にワークフロー画面キャプチャ + テキスト「自動化0円」
- 公開後48-72時間でA/Bテスト実施、ウォッチタイム基準で勝者選定
