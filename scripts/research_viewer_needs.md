## よくある質問・悩みTOP20

### 基本理解（1-5）

1. **n8nって何？何が自動化できるの？**
   - 「ノーコードで業務自動化」と言われてもピンとこない。具体的に何ができるのか知りたい。

2. **n8nの読み方がわからない（エヌエイトエヌ）**
   - 初めて見た人が最初に検索すること。「nodemation」の略であることも知られていない。

3. **Make / Zapier / Difyとの違いは？どれを選べばいい？**
   - 類似ツールが多く、自分に合うものがわからない。n8nは「開発者向け」と言われ敬遠する人もいる。

4. **料金はいくら？本当に無料で使えるの？**
   - クラウド版（月額20ユーロ〜）とセルフホスト版（完全無料）の違いが混乱を招く。実行回数ベース課金も理解しにくい。

5. **プログラミング知識がなくても使える？**
   - 「ノーコード」と謳いつつ、JSONやAPIの知識が必要になる場面がある。本当に非エンジニアでもできるのか不安。

### 始め方・セットアップ（6-10）

6. **クラウド版とセルフホスト版、どちらで始めればいい？**
   - 初心者はクラウド版が推奨だが、セルフホスト版の無料・無制限が魅力的で迷う。

7. **セルフホストの環境構築がわからない（Docker / VPS）**
   - Docker、VPS、ドメイン設定、SSL証明書など、非エンジニアにはハードルが高い。

8. **最初に何を自動化すればいい？**
   - 「自動化したいことがない」「何ができるかわからないので始められない」という鶏と卵の問題。

9. **外部サービスとの接続方法（API Key / OAuth）がわからない**
   - Google、Slack、OpenAIなどの認証設定でつまずく人が非常に多い。

10. **テンプレートの使い方がわからない**
    - 5,000以上のテンプレートがあるが、自分の環境に合わせてカスタマイズする方法がわからない。

### 操作・技術的な悩み（11-15）

11. **ノードの設定項目が多すぎて何を入れればいいかわからない**
    - Resource? Operation? といった専門用語が並び、何を選択すべきか不明。

12. **JSONデータの構造が理解できない**
    - ノード間のデータ受け渡しがJSONで行われるが、構造の読み方がわからずエラーになる。

13. **エラーメッセージが英語で意味がわからない**
    - 「401 Unauthorized」「500 Internal Server Error」などのエラーへの対処法がわからない。

14. **ワークフローのデバッグ方法がわからない**
    - どのノードでエラーが起きているか特定できない。実行ログの見方もわからない。

15. **Webhook（ウェブフック）の仕組みが理解できない**
    - トリガーとしてよく使われるが、概念自体を理解していない初心者が多い。

### 応用・実践の悩み（16-20）

16. **AIエージェントの作り方がわからない**
    - n8nでのAI Agent構築に興味はあるが、LLMノード・メモリ・ツールの組み合わせ方が不明。

17. **ChatGPT / OpenAI APIの連携手順がわからない**
    - API Keyの取得方法、課金の仕組み、n8nでの設定方法がセットで知りたい。

18. **作ったワークフローが本番で安定しない**
    - テスト時は動くが、本番環境でエラーハンドリングやレート制限に引っかかる。

19. **複雑なワークフローの設計方法がわからない**
    - 分岐処理、ループ、マージなど、高度なロジックの組み方がわからない。

20. **MCP（Model Context Protocol）って何？どう使うの？**
    - 2026年の最新トレンドだが、概念の理解も実装方法もわからない。

## つまずきポイント（初心者が挫折する場所）

### レベル1: 入口で止まる

| つまずきポイント | 詳細 |
|----------------|------|
| **ツール選択で迷子** | n8n / Make / Zapier / Dify の違いがわからず、比較記事を読み漁って時間を浪費する |
| **環境構築で挫折** | セルフホスト版を選んだ場合、Docker / VPSの知識がなく最初の起動すらできない |
| **英語UIへの抵抗** | n8nは日本語UIが未対応。英語が苦手だと操作画面を見ただけで萎える |
| **何を自動化すべきかわからない** | 自分の業務でどこが自動化できるのか想像がつかない |

### レベル2: 最初のワークフローで詰まる

| つまずきポイント | 詳細 |
|----------------|------|
| **認証設定（OAuth / API Key）** | Google, Slack等の外部サービス接続時にOAuth設定やAPIキー取得でエラーが出る |
| **ノードの選択と設定** | 数百種類のノードから適切なものを選べない。設定項目の意味がわからない |
| **JSONデータの理解** | ノード間のデータがJSON形式で流れることを理解できず、データのマッピングに失敗する |
| **Webhookの概念理解** | URLを外部に公開してデータを受け取る仕組みが直感的に理解できない |

### レベル3: 実践で壁にぶつかる

| つまずきポイント | 詳細 |
|----------------|------|
| **エラーハンドリング未設定** | 正常系だけ考えて設計し、外部APIのタイムアウトやレート制限で本番が止まる |
| **いきなり複雑なものを作ろうとする** | 完成品イメージから逆算せず、最初から壮大なワークフローを作って失敗する |
| **デバッグスキル不足** | どのノードで問題が起きているか特定できない。実行ログの活用方法を知らない |
| **データ変換の壁** | 異なるサービス間のデータ形式の違い（日付フォーマット、文字コード等）に対応できない |

### レベル4: 運用で困る

| つまずきポイント | 詳細 |
|----------------|------|
| **バージョンアップ対応** | セルフホスト版のアップデート手順がわからない |
| **セキュリティ設定** | 本番運用時のセキュリティベストプラクティスがわからない |
| **パフォーマンス問題** | 大量データ処理時のメモリ不足やタイムアウトへの対応 |

## 視聴者が動画に求めていること

### 1. 「全体像」をまず見せてほしい

> n8nとは何か、何ができるのか、自分に必要なのかを**3分以内**で判断したい。
> 技術詳細よりも「こんなことが自動でできるようになる」というビフォーアフターが見たい。

### 2. 画面を見せながら一緒に手を動かしたい

> テキスト記事では操作イメージが湧かない。
> 実際の画面操作を見ながら「同じことをやればできる」状態にしてほしい。
> 「ここをクリック」「ここに入力」レベルの丁寧さが求められている。

### 3. 完成形を先に見せてから手順を解説してほしい

> 最終的にどんなワークフローができるのかを最初に提示してほしい。
> ゴールが見えないまま手順だけ追いかけると不安になる。

### 4. 「なぜそうするのか」を説明してほしい

> 手順だけでなく、なぜそのノードを選ぶのか、なぜその設定にするのかの理由を知りたい。
> 理由がわかれば応用ができる。

### 5. エラーが出た時の対処法も見せてほしい

> チュートリアルでは「うまくいく前提」で進むが、実際にはエラーが出る。
> よくあるエラーとその対処法をセットで見せてほしい。

### 6. 実用的なユースケースが見たい

> 「Hello World」的なデモではなく、実際の業務で使える具体例が見たい。
> 営業、マーケ、バックオフィスなど、職種別の活用例が求められている。

### 7. 日本語で丁寧に解説してほしい

> n8nの日本語情報は圧倒的に少ない。英語ドキュメントを読むのはハードルが高い。
> 日本語での丁寧な解説動画には大きな需要がある。

### 8. 最新のAI機能（エージェント / MCP）を知りたい

> n8n + AI の組み合わせに最も興味がある層が増えている。
> AIエージェントの作り方、MCPサーバーの設定方法など、最新トレンドを押さえたい。

## 日本語視聴者特有のニーズ

### 1. 日本語情報の圧倒的な不足

- n8nの公式ドキュメント・UIは英語のみ。日本語へのローカライズは2026年4月時点で未対応
- 日本語の解説記事は増加傾向だが、ブログ記事が中心でYouTube動画は非常に少ない
- 英語のYouTubeチュートリアルは豊富だが、日本語話者にはハードルが高い
- **日本語でのn8n解説動画は「ブルーオーシャン」状態** -- 先行者利益が大きい

### 2. 英語UIへの対処法の需要

- ブラウザの翻訳機能を使う方法の紹介が求められている
- 重要な英語用語（Node, Trigger, Workflow, Credential, Expression等）の日本語対訳リスト
- エラーメッセージの日本語での解説

### 3. 日本のビジネス環境に合った事例

- Google Workspace（Gmail, スプレッドシート, カレンダー）との連携事例
- Slack / ChatWork / LINE Worksなど日本で使われるツールとの連携
- kintone / freee / MoneyForward等の日本固有SaaSとの連携可能性
- 日本の商習慣に合った業務フロー（請求書処理、稟議、勤怠管理等）

### 4. セルフホストへの関心の高さ

- 日本企業はデータの国外保存に慎重。セルフホスト版への関心が特に高い
- さくらVPS、ConoHa、Xserver等の日本のVPSサービスでの構築手順を求める声がある
- 月額500〜2,000円でサーバー運用できるという情報に惹かれる層が多い

### 5. AI連携への興味（特にChatGPT）

- 日本ではChatGPTの認知度が圧倒的に高い。「n8n + ChatGPT」の組み合わせへの関心が最大
- OpenAI APIの従量課金の仕組みと実際のコスト感を知りたい
- Claude、Geminiとの連携方法も併せて紹介すると差別化になる

### 6. 「非エンジニアでもできる」安心感

- 日本の視聴者層は非エンジニアの割合が高い
- 「プログラミング不要」「ノーコード」を強調しつつも、JSONやAPIの最低限の知識が必要なことを正直に伝えることが信頼につながる
- 「難しそう」という第一印象を払拭する導入部分が重要
