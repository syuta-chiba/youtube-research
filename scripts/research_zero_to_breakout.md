# ゼロから伸びたAI系チャンネルの初期戦略

## 事例1: Nate Herkの最初の動画

### 背景
- Nate Herkelman（アイオワ大学卒、ビジネスアナリティクス&マーケティング専攻）
- ゴールドマン・サックスでBIアナリストとして勤務。社内でAlteryx等を使った自動化を構築
- コーディング経験なし。ただし「手を離しても動くシステム」を作ることに熱中していた
- 従来の自動化では「推論が必要なタスク」に限界を感じ、AI+自動化の組み合わせに注目

### 初期の動き（2024年9月〜）
- **2024年9月**: 最初のYouTube動画を投稿。大きな計画はなく、AI自動化について学んだことをドキュメント化するスタンスで開始
- **コンテンツ**: n8nを使ったノーコードAIエージェントのチュートリアル。非エンジニアでも再現できる実践的なビルド動画
- **差別化**: 「コーディングできない人間がAIエージェントを作る」というポジショニング
- **転換点**: ある視聴者から「動画で作ったものをカスタムで作ってほしい」というメールが届く。これが事業化のきっかけに

### 成長の軌跡
- 2024年9月: チャンネル開始
- 2024年11月: ゴールドマン・サックスを退職（わずか2ヶ月でフルタイム移行を決断）
- 開始から6ヶ月: **10万登録者達成**
- 2025年6月: 23万登録者超
- 毎日8件の質の高いインバウンドリードが発生

### 最初の1万再生を獲得した要因
1. **ニッチの正確な選定**: 「n8n × AIエージェント × ノーコード」という当時ほぼ競合がいないニッチ
2. **再現可能なチュートリアル**: 視聴者がそのまま真似できるステップバイステップ
3. **無料テンプレート配布**: 動画で作ったワークフローのテンプレートを無料提供
4. **Skoolコミュニティ連携**: AI Automation Societyコミュニティで視聴者との関係構築
5. **実ビジネスの裏付け**: 「$23,000をたった4つのエージェントで稼いだ」等、具体的な数字で信頼性を獲得

## 事例2: Nick Saraevの初期

### 背景
- カナダ在住、2019年（ChatGPT以前）からAI画像・言語モデルを使った事業を構築
- コンテンツエージェンシー1SecondCopyを$90K/月まで成長、Dental Media Corpを$2M/年まで拡大
- 実業家としての実績がコンテンツの土台

### 初期の動き
- YouTube開始時、最初は幅広いトピックで実験的に投稿
- **最初の数週間は平均50再生程度**で全く伸びなかった
- 収益化開始初日の収益は**$38.41**。ただしCPMは平均の数倍（高収入視聴者層がターゲット）
- 6ヶ月で新チャンネルを本格軌道に乗せ、LinkedInで「25倍成長」を報告

### 成長の軌跡
- 最初の数週間: 1動画あたり約50再生
- 2024年: 約38,000人の登録者を獲得
- 2026年3月時点: 307,845登録者（1日1,500〜2,000人増）
- 2026年末目標: 100万登録者

### 最初の1万再生を獲得した要因
1. **圧倒的な投稿頻度**: 少なくとも1日1本の長尺動画を2チャンネルで投稿、Instagramも毎日
2. **「完璧さより実行」の姿勢**: 動画のプロダクション品質は高くない。実行スピードが全て
3. **実績ベースの権威性**: 「先月$102,514稼いだ方法」等、自身の事業実績をコンテンツ化
4. **Make.com/n8n等の具体的ツールチュートリアル**: 検索流入を狙える実践的内容
5. **高CPMニッチの選択**: オートメーション・ビジネス系は広告単価が高い

## 事例3: AIでサボろうチャンネルの初期

### 背景
- ソフトウェアエンジニア歴10年、直近2年はLLMを使ったアプリケーション開発が主戦場
- 「プログラミングを必要としないAI活用方法」を伝えるコンセプト
- チャンネル名: 「AIでサボろう」= AIを使って面倒なことを自動化し、楽をしよう

### 初期の数字（衝撃的なV字回復）
- **初月**: 総再生回数 **70回**、チャンネル登録 **8人** → 絶望
- **2ヶ月目**: 総再生回数 **20,000回**、チャンネル登録 **1,200人** → 急成長

### 最初の1万再生を獲得した要因
1. **「絶望からの改善」サイクル**: 初月の失敗を分析し、2ヶ月目で大幅に改善
2. **ターゲット明確化**: 「非エンジニアのためのAI活用」という明確なポジション
3. **note.comでの振り返り発信**: YouTube以外のプラットフォーム（note）で運営の裏側を公開し、相互流入を生む
4. **日本語AI情報の需要ギャップ**: 英語圏に比べ日本語のAI実用チュートリアルが少なかった
5. **100日チャレンジ**: 継続的な投稿により、2ヶ月目にアルゴリズムに認識される
6. **後に書籍化**: 「AI活用の教科書」「非エンジニアのためのAIコーディングの教科書」を出版

## 事例4: Fireship（Jeff Delaney）の初期

### 背景
- 元々Angular + Firebaseの開発者
- 当時、この2技術に関する良質なコンテンツが不足していた
- 動画制作の経験ゼロからスタート

### 初期の動き
- **最初期**: Angular + Firebaseのニッチチュートリアルのみ投稿
- **2018年6月**: 初のFirebase以外の動画「VS Code Top-Ten Pro Tips」を投稿 → **100万再生超**のブレイクスルー
- **2018年9月**: チャンネル形式を「汎用的なソフトウェア開発チャンネル」に転換
- **2019年1月**: チャンネル名を「Fireship」にリブランド

### 成長の鍵
1. **超ニッチから開始 → 徐々に拡大**: Angular/Firebase → VS Code → 汎用プログラミング
2. **ブレイク動画の特徴**: 「VS Code Tips」= **多くの開発者が検索する汎用的なトピック**
3. **短く・速く・面白く**: 100秒シリーズ等、圧倒的にテンポの良いフォーマットを開発
4. **皮肉なユーモア**: プログラマーのニッチジョークとミームで差別化
5. **現在**: 300万登録者超、総再生数2億回

### 教訓
- ニッチで始めて信頼性を築き、ブレイク動画は「より広いオーディエンスが検索するトピック」で狙う

2. **既存の基盤活用**: 長年のYouTube経験とデジタルマーケティングの知見
3. **ツール連携**: FutureTools.ioとYouTubeの相互送客

## 最初の5本の動画で何を出すべきか

### 動画1: 「Claude Codeとは何か？5分でわかる完全ガイド」
- **狙い**: 検索キーワード「Claude Code とは」「Claude Code 使い方」を獲得
- **内容**: Claude Codeの概要、インストール方法、基本的な使い方
- **ターゲット**: 「Claude Codeって聞いたけど何？」という初心者層
- **参考モデル**: Fireshipsの「100 Seconds of XXX」シリーズ

### 動画2: 「プログラミング経験ゼロの僕が、Claude Codeで自動化ツールを作ってみた」
- **狙い**: 「非エンジニアでもできる」フックで幅広い視聴者を獲得
- **内容**: 実際に何か便利なツール（例: メモアプリ、タスク自動化）をClaude Codeでゼロから作る過程
- **ターゲット**: 「AIでプログラミングができるらしい」と興味を持っている非エンジニア
- **参考モデル**: Nate Herkの「ノーコードAIエージェント」チュートリアル

### 動画3: 「n8n × Claude で作る全自動リサーチエージェント【無料テンプレート付き】」
- **狙い**: 「n8n Claude」「AIエージェント 自動化」等の検索キーワード獲得
- **内容**: n8nとClaude APIを組み合わせて、特定のトピックを自動リサーチするエージェントを構築
- **差別化**: 無料テンプレートをダウンロード可能にする（リード獲得にもなる）
- **参考モデル**: Nate Herkのn8nチュートリアル形式

### 動画4: 「ChatGPT vs Claude Code：どっちを使うべき？【正直比較】」
- **狙い**: 比較系は検索ボリュームが大きい。「ChatGPT vs Claude」は常に検索される
- **内容**: 具体的なタスク（コード生成、文章作成、データ分析）で両者を比較
- **差別化**: 「忖度なし、正直な比較」スタンス（AIでサボろうチャンネルの正直さモデル）
- **参考モデル**: Matt Wolfeのツール比較動画

### 動画5: 「AIで副業を始めて最初の1週間で起きたこと【リアル報告】」
- **狙い**: 「AI 副業」は検索ボリューム大。ストーリーテリングで視聴維持率を上げる
- **内容**: 実際にAIを使って何かしらの収益を上げる試み（自動化ツールの受託、AIアプリ制作等）のリアルな記録
- **差別化**: 成功も失敗も含めたドキュメンタリー形式
- **参考モデル**: AIでサボろうチャンネルの「初月70回再生」の正直さ

### 5本全体の戦略
| 要素 | 方針 |
|------|------|
| 投稿ペース | 初月は週2本以上（5本を2.5週で出し切る） |
| サムネイル | 高コントラスト、3〜5語のテキスト、具体的な数字 |
| タイトル | ツール名 + 具体的成果/数字を必ず含める |
| 説明欄 | 150〜300語、キーワード込み、タイムスタンプ必須 |
| CTA | テンプレート配布 → メーリングリスト or Discord登録へ誘導 |
| SNS連携 | 各動画のハイライトをX（Twitter）とnoteで発信 |
| フック | 最初の3秒で「この動画を見ると何ができるようになるか」を宣言 |

### 期待値
- Nate Herkの事例: 最初の2ヶ月で急成長開始
- AIでサボろうの事例: 初月は70再生でも2ヶ月目に20,000再生
- **最初の5本で結果が出なくても正常。10〜15本目で最初のブレイクが来ることが多い**
- 最初の1ヶ月は「アルゴリズムに認識してもらう」ための助走期間
