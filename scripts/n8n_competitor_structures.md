## 共通パターン分析

### 1. 全動画に共通する構成要素

**フレームワーク: HOOK → FOUNDATION → BUILD → SCALE → CTA**

| 段階 | 内容 | 典型的な時間配分 |
|------|------|----------------|
| HOOK（冒頭） | 「何が作れるか」「いくら稼げるか」の約束 | 0-5分 |
| FOUNDATION（基礎） | n8nとは、セットアップ、UI操作、基本概念 | 全体の10-15% |
| BUILD（構築） | 段階的に複雑になるワークフロー構築 | 全体の60-70% |
| SCALE（応用） | 高度な技術（エージェント、マルチエージェント、API） | 全体の15-20% |
| CTA（誘導） | 有料コミュニティ・テンプレート誘導 | 最後の2-5分 |

4. **Part/Section制で構造化** - 進捗感を持たせる
5. **API/エージェントは後半に配置** - 基礎を固めてから
6. **エラーハンドリング・ベストプラクティスは終盤** - 実践の後に理論
7. **最後に「Next Steps」で有料コミュニティ誘導**
