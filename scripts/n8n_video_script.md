### 8:00-14:00 実践1: AIメール自動返信ワークフロー（6分）
```
「では、最初のAIワークフローを作りましょう。
"Gmailにメールが来たら、AIが内容を読んで、
返信のドラフトを自動で作成する"
というワークフローを作ります。」
```

#### ステップ1: トリガー設定（1分30秒）
- **画面**: Gmail Triggerノードを追加
  - アカウント接続
  - 「新着メール受信時」を選択
  - テスト実行で受信メール確認

#### ステップ2: AI処理（2分）
- **画面**: AI Agentノードを追加
  - OpenAI APIキーを設定（取得方法も簡単に説明）
  - システムプロンプトを設定:
```
あなたはビジネスメールの返信アシスタントです。
受信メールの内容を理解し、丁寧で適切な返信ドラフトを
日本語で作成してください。
```
  - 入力に「メール本文」を指定

#### ステップ3: 出力設定（1分）
- **画面**: Gmail（下書き作成）ノードを追加
  - AI の出力を返信本文に設定
  - 宛先を元のメール送信者に設定

#### ステップ4: テスト＆有効化（1分30秒）
- **画面**: ワークフロー全体をテスト実行
  - 結果を確認（「おー、ちゃんとドラフトが作られてる！」）
  - ワークフローをアクティブに切り替え
```
「これで、メールが来るたびに
AIが自動で返信ドラフトを作ってくれます。
朝起きたら返信の下書きが全部揃っている、
そんな世界が今日から手に入ります。」
```

### 14:00-18:30 実践2: YouTube動画の自動要約（4分30秒）
```
「次はもう少し面白いワークフローを作ります。
YouTubeの動画URLを入れると、
AIが自動で文字起こしして、
要約をGoogleスプレッドシートに保存する
ワークフローです。」
```

#### ステップ1: Webhookトリガー（1分）
- **画面**: Webhookノードを追加
  - URLを取得
  - テスト用にYouTube URLをPOST

#### ステップ2: YouTube文字起こし（1分）
- **画面**: HTTP Requestノード
  - YouTube Transcript APIで文字起こしを取得

#### ステップ3: AI要約（1分30秒）
- **画面**: AI Agentノード
  - プロンプト: 「以下のYouTube動画の文字起こしを、箇条書き5つで要約してください」
  - Claude APIを使用（長文処理に強い）

#### ステップ4: スプレッドシートに保存（1分）
- **画面**: Google Sheetsノード
  - タイトル、URL、要約、日時を自動記録
  - テスト実行 → スプレッドシート確認

  - 最新3記事を取得

  - プロンプト: 各記事から、280文字以内のX投稿文を3パターン生成
  - ハッシュタグ自動付与

#### ステップ4: 通知（1分）
- **画面**: Slackノード or LINEノード
  - 生成された投稿文を自分に通知
  - 気に入ったものをコピペで投稿
