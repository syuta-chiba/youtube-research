## 4. ハッシュタグ設定

### 基本ルール（2026年最新）

- **ハッシュタグ数: 3-5個が最適**（25%多くの視聴回数を獲得するデータあり）
- 15個を超えると**全てのハッシュタグが無効化**される
- 説明欄に入れた最初の3つがタイトル上部に表示される
- 無関係なハッシュタグ（#viral, #trending等）はペナルティリスク

### 推奨ハッシュタグセット

#### 日本語動画用

| 動画タイプ | ハッシュタグ |
|-----------|-------------|
| 入門・チュートリアル | `#n8n #AI自動化 #ノーコード` |
| AIエージェント系 | `#n8n #AIエージェント #自動化` |
| ビジネス活用 | `#n8n #業務効率化 #AI活用` |
| 比較・レビュー | `#n8n #自動化ツール #ノーコード` |
| ワークフロー紹介 | `#n8n #ワークフロー #自動化` |

#### 英語動画用

| 動画タイプ | ハッシュタグ |
|-----------|-------------|
| Tutorial | `#n8n #AIAutomation #NoCode` |
| AI Agent | `#n8n #AIAgent #WorkflowAutomation` |
| Business | `#n8n #AutomationBusiness #AI` |
| Comparison | `#n8n #AutomationTools #NoCode` |

### ハッシュタグ配置のベストプラクティス

1. **説明欄の最後**にハッシュタグを配置（最初の3つがタイトル上に表示される）
2. **1つ目**: コアトピック（#n8n）
3. **2つ目**: カテゴリ（#AI自動化、#AIAutomation）
4. **3つ目**: コミュニティ（#ノーコード、#NoCode）
5. #viral や #trending は絶対に使わない（ペナルティ対象）

## 5. チャプター設計のSEO効果

### チャプターがSEOに与える効果

| 効果 | 説明 |
|------|------|
| Google「キーモーメント」表示 | チャプター付き動画はGoogle検索結果に「キーモーメント」として表示され、各セクションに直接ジャンプ可能。CTR向上 |
| 複数検索エントリーポイント | 各チャプターが独立してGoogle検索に表示される可能性。1動画で複数のキーワードを狙える |
| ロングテールキーワード対応 | チャプタータイトルにニッチなキーワードを含めることで、長尾検索に対応 |
| 視聴体験の向上 | ユーザーが目的のセクションに直接ジャンプ → 満足度UP → アルゴリズム評価UP |
| 視聴維持率の改善 | チャプターにより「もう少し見よう」効果。離脱率を低減 |

### チャプター設計のルール

1. **0:00から開始**する（必須。これがないとチャプターが認識されない）
2. **最低3つ以上**のチャプターが必要
3. **各チャプター10秒以上**の長さが必要
4. **90-120秒間隔**が2026年の推奨（短すぎると逆効果）
5. チャプタータイトルにキーワードを含める

## 7. Google検索にも表示させる方法

### YouTube動画をGoogle検索に表示させる7つの戦略

#### 1. 「How to」キーワードを狙う

Googleは「方法」「やり方」系の検索に対してYouTube動画を優先表示する傾向がある。

```
狙うべきキーワード例:
- "n8n 使い方"
- "n8n AIエージェント 作り方"
- "n8n ワークフロー 作成方法"
- "how to build AI agent n8n"
- "how to automate with n8n"
```

#### 2. チャプター（タイムスタンプ）を必ず設定

- Googleの「キーモーメント」機能で検索結果に動画の各セクションが表示される
- チャプタータイトルにターゲットキーワードを含める
- 各チャプターが独立した検索エントリーポイントになる

#### 3. 説明欄を200語以上書く

- Googleは説明欄のテキストをインデックスする
- 最初の2-3行に主要キーワードを含める
- 自然な文章でキーワードを散りばめる（キーワードスタッフィングは逆効果）

#### 4. 字幕・トランスクリプトを活用

- YouTube自動字幕ではなく、手動字幕をアップロード
- 字幕テキストもGoogleのインデックス対象
- 2026年では字幕付き動画の検索順位が優遇される傾向

#### 5. タイトルにキーワードを前方配置

- 主要キーワードをタイトルの最初の40文字以内に配置
- タイトルは60文字以内を推奨
- Googleとの連動を考慮し、検索されやすいフレーズを使用

#### 6. 高い視聴維持率を確保する

- **視聴維持率がGoogle掲載の最大要因**
- 7分の動画で90%維持 ＞ 20分の動画で50%維持
- フック（冒頭15秒）で離脱を防ぐ
- CTR（クリック率）3%以上を目指す

#### 7. プレイリストのSEO最適化

- プレイリストタイトルにキーワードを含める
- プレイリスト自体がGoogle検索に表示される
- テーマ別に整理し、連続視聴を促進

### Google検索表示に有効なキーワードパターン

| パターン | 例 |
|----------|-----|
| How to + ツール名 | how to use n8n, n8n 使い方 |
| ツール名 + tutorial | n8n tutorial, n8n チュートリアル |
| 比較系 | n8n vs Make, n8n vs Zapier |
| 年号入り | n8n tutorial 2026, n8n 使い方 2026 |
| ベスト系 | best automation tool 2026 |
| 初心者向け | n8n for beginners, n8n 初心者 |

## 8. まとめ：SEO最適化チェックリスト

動画公開前に確認するチェックリスト:

- [ ] タイトル: 主要キーワードが最初の40文字以内にある
- [ ] タイトル: 60文字以内に収まっている
- [ ] 説明欄: 最初の2-3行にフック文+主要キーワード
- [ ] 説明欄: 200語以上の説明文
- [ ] 説明欄: キーワードが自然に2-3回含まれている
- [ ] 説明欄: チャプター（タイムスタンプ）が設定済み（0:00開始、3つ以上）
- [ ] 説明欄: 重要リンクが上部に配置（5-7個以内）
- [ ] 説明欄: CTA（チャンネル登録、テンプレートDL等）が明記
- [ ] タグ: 5-8個設定済み（主要キーワード+関連キーワード）
- [ ] ハッシュタグ: 3-5個設定（説明欄の最後）
- [ ] ハッシュタグ: 最初の3つが最重要（タイトル上に表示される）
- [ ] ピン留めコメント: 質問型 or CTA型を用意
- [ ] サムネイル: CTR 3%以上を目指すデザイン
- [ ] 字幕: 手動字幕をアップロード（または自動字幕を確認・修正）
- [ ] プレイリスト: 適切なプレイリストに追加済み
